出展構想：KASUGAI Canvas — GIS 利活用を促進する Agentic AI エージェント

出展タイトルは 「KASUGAI Canvas — GIS 利活用を促進する Agentic AI エージェント」 です。ブラウザ内蔵の AI エージェント（Gemini API function calling）が自然言語の指示から空間情報レイヤーを自動構築し、FlyTo・資料生成まで行う構成で、Cloud Run を稼働・保存先とした実装済みの機能のみで出展します。本ページに記載する機能はすべて実装済みで、審査用の公開 URL でそのまま確認できます。

参加条件との対応

本ハッカソンの参加条件（必須プロダクト・必須 AI 技術・提出物）に対し、KASUGAI Canvas は以下のように対応します。

審査基準への対応

審査基準KASUGAI Canvas のアピールポイント
課題の新規性と解決策の有効性「GIS が導入前に体験できず、理解されないまま失敗する」という未解決課題に対し、サンプルデータ自動生成×資料×GIS 連動という体験先行型アプローチで解決
自律性・エージェントらしさ自然言語の指示からブラウザ内蔵エージェントが function calling ループを自律実行し、レイヤー選定→サンプル GeoJSON 生成→課題抽出→資料作成までを一連のツール呼び出しとして完了する。実行したツールはチャットに記録され、生成データには出典・生成時刻・AI 生成明記を付与できる（可観測性）
実装品質と拡張性公開エンドポイントのガバナンスを実装済み：/api/gemini はモデル許可リスト・1MB 上限・レート制限・Bearer トークン／ID-PASS／Cookie ゲート／IAP の認可で保護。データ転送は GCS V4 署名付き URL でコンテナを通さず、セッションはステートレス HMAC トークンでアフィニティ不要。外部エージェントプロトコルが契約としてフロントに開いているため、後から別実装のエージェントを差し込み拡張できる

実装済み機能の概要

  • 内蔵AIエージェント（ブラウザ側）：Gemini API の function calling で48種のチャットツールを実行し、「○○の資料を作って」→ レイヤー自動構成（addLayer/addDataLayer）→ サンプル GeoJSON 生成（addGeoJsonLayer）→ FlyTo → 資料出力（showReport、Markdown/HTML・ダウンロード可）→ 視点パーマリンク埋め込み（buildShareUrl）まで一連の流れを完結。生成データには出典・生成時刻・AI生成明記を付与でき、実行ツールはチャットに記録される（可観測性）
  • AI プロキシ（キー隠蔽）：POST /api/gemini がサーバーの GEMINI_API_KEY を注入して転送（モデル許可リスト・1MB 上限・レート制限・認証モードで保護）。BYO キー登録済みのブラウザは Gemini を直接呼び、未登録でも /api/capabilities の aiProxy 通知で自動的にサーバーキー経由になるため審査員はキー不要
  • 保存・認証：ID/PASS ログイン（/api/auth）で HMAC トークンを発行し、.kasc と gs:// データを Cloud Storage に保存（/api/kasc・/api/data/<key>、GET は V4 署名付き URL でブラウザ⇄GCS 直接転送）。起動時に同梱 .kasc を冪等シード。審査用 URL は認証モード5で運用中
  • キー・秘匿管理：Gemini・Maps キーと認証情報は Secret Manager 経由で環境変数に注入。Maps キーはブラウザ直接通信に必要なため capabilities で配布し、GCP 側の HTTP リファラ＋API 制限で保護
  • 拡張窓口：外部エージェントプロトコル（{message,project,camera,layers,history,apiKey?} → {reply,actions,report}）により、別実装のエージェントをエンドポイント URL 指定で差し込める

デモシナリオ（3分動画）：「避難所の資料を作って」→ サンプルレイヤー自動追加 → FlyTo → 属性から課題抽出 → パーマリンク付き資料出力の一連の流れ。保存面はログイン → .kasc が GCS に保存され再訪時に復元される流れを収録します。

システムアーキテクチャ図

実線はサーバー経由、破線はブラウザ直接の通信です。Gemini キーは Secret Manager から Cloud Run の環境変数に注入され /api/gemini が転送時に付与するためブラウザには現れません。Maps キーはブラウザの直接通信に使われるため /api/capabilities で配布し、GCP 側の HTTP リファラ制限＋API 制限で保護します。
