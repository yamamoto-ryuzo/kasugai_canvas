V3: AI 連携

Gemini API を使った AI チャットによる地図操作と、ブラウザ内コード実行の基盤です。詳細・設定手順は Google 連携・AI を参照してください。

🗨️ AI チャット（Gemini 連携）

設定 → Google で API キーを登録し、右下のチャットパネルから自然言語で地図を操作。function calling で flyTo・レイヤー/ベースマップ切替・検索・カメラプリセット・地形/効果・Fly パス・プロジェクト切替などを実行。履歴はプロジェクト単位で保存。APIキー未設定時はローカルコマンド（/fly 等）が使える

🧪 runCode サンドボックス

AI が生成した JavaScript を opaque origin iframe + postMessage ブリッジで安全に実行し、地図を操作するブラウザ内コード実行基盤

🔌 kasugaiApi

window.kasugaiApi で viewer・カメラ・レイヤー・イベントに外部からアクセスする操作 API。プラグイン・外部エージェントの土台
