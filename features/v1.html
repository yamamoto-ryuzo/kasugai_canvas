V1: GIS 基本機能（Re:Earth GeoSuite 上位互換）

Re:Earth GeoSuite の GIS・デジタルツイン機能を包含し、KASUGAI 独自の拡張を加えた上位互換の実装です。

📝 インスペクター一括設定

xyz: / 3dtiles: / geojson: / geoparquet: / flatgeobuf: / gpkg: / duckdb: / sql: / base: / info: / cam: / legend: 等を行単位で一括設定

🗺️ ベースマップ

base: または xyz: 行で指定。Basemap セレクタから 1 つだけアクティブ化。「ベースマップなし」「ベースマップ透明（地表色と背景を透過し、XYZ ドレープと地形の高さは維持）」も選択可能。セレクタ横の 🌐 アイコンで、現在の視点（位置・高度・方位・傾き）を Google Earth 形式に変換して新しいウィンドウで開く

🔧 システムレイヤ制御

layer: 行で既存レイヤー名を指定し、表示 / 非表示を初期制御

➕ レイヤー追加・管理

XYZ タイル、3D Tiles、GeoJSON を URL 指定で追加。Layers パネルで表示切替

📑 レイヤー一覧UI

読み込んだレイヤーの表示切替、並び順変更、設定の永続化を視覚的に操作。各行の📍ボタンでレイヤー全体にフォーカス

📂 レイヤグループ化

/ 通常グループ、// 排他グループ。ラジオボタンのような排他制御

🖼️ 凡例表示

legend: 行で画像 URL を指定。Legend タブに凡例画像を一覧表示

🔎 住所検索

国土地理院 / Yahoo ジオコーダ API を使い、住所・施設名で検索＋ FlyTo

🧬 ベクトル検索

全件読み込み系ベクター（GeoJSON/GeoParquet/FlatGeobuf）の属性値をレイヤー・属性・文字列で絞り込み FlyTo。対象は「全選択（非表示・未読込レイヤーも検索時に読み込んで対象化）」「表示レイヤ（表示中のみ）」「個別レイヤー（未読込は選択時に読み込み）」から選択

📊 属性・値一覧

全ベクターレイヤー（非表示・クエリ系含む）の属性を一覧。文字列検索・列ソート・行クリック FlyTo

🎥 カメラプリセット

cam: 行で登録した位置へワンクリック FlyTo。緯度・経度・高さ・ピッチ・方位を設定

ℹ️ Info 表示

info: 行で外部 HTML を Info タブに表示。プロジェクト説明やドキュメントを埋め込み

📤 Share（位置情報共有）

カメラ位置を URL ハッシュに保存。共有 URL コピーで同じ視点を共有

🗺️ GeoJSON 3D ドレープ制御

地面 / Terrain / 3D Tiles のどれに張り付くかをインスペクター行または設定で切替

🛡️ ベクター描画件数の上限

設定タブで entity 描画の合計件数を制限（既定 20000・0=無制限）。超過レイヤーは表示範囲内の地物のみ描画しカメラ移動で追随。検索・属性は常に全件対象

⛰️ Terrain / Shadow

地形表示と影表示の ON/OFF をワンクリックで切り替え。地形ソースは Re:Earth(楕円体高 / 標高)と国土地理院 DEM(5m+10m / 1m、TP基準)から選択可能

🧭 ナビゲーション

方位コンパス、2D / 3D 切替、Orbit / Fly モード切替、北リセット

📊 属性（Attr）表示

地物をクリックすると属性を一覧表示。重なった地物（ポリゴン等）は件数付きのヘッダー一覧（手前から順）になり、行をクリックで個別に属性を展開。3D Tiles（構造化メタデータ）・ベクター（entity/primitive）の各描画経路に対応

🌐 多言語対応（8言語）

UI は英語・日本語・中国語・韓国語・スペイン語・フランス語・ドイツ語・ポルトガル語の 8 言語に対応。設定 → その他の言語セレクタで即時切替。初回はブラウザ言語から自動判定（未対応時は英語）、選択は localStorage に保存。AIチャットの回答言語も UI 言語に追随

設定書式の詳細は .kasc 設定仕様、バージョン横断の実装詳細（描画順・ドレープ・高さ基準・制限）は V0: システム基本構成 を参照してください。
