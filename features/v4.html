V4: プラグイン（認証機構）・外部連携

拡張可能なプラグイン機構と認証方式の導入に加え、データ形式・外部サービス連携を大きく拡充しました。

🧩 プラグイン機構・認証方式

起動前の認証プラグイン（auth-selector）と起動後の通常プラグイン（plugin-loader）を分離した拡張機構。認証方式は 0〜7（認証なし / ローカル / 簡易パスワード / Cloudflare Pages / Workers / Cloud Run / IAP）から選択

🗃️ クエリ系・大規模ベクター

duckdb: / sql: / gpkg: 行タイプで DuckDB-WASM・SQLite WASM による SQL 絞り込みレイヤー。GeoParquet・FlatGeobuf・GeoPackage を直接読み込み、bbox 連動・where 絞り込み・属性列プルーニングに対応。ベクター描画件数の上限・primitive バッチ描画で大規模データにも対応

🗺️ Google Maps Platform 連携

Geocoding / Places のハイブリッド検索、Street View リンク・候補ラインオーバーレイ。外部エージェント呼出し（エージェントタブにエンドポイントを設定し POST {message, project, camera, layers, history} → actions を実行）で Antigravity 等の外部構築エージェントと接続可能

認証方式の詳細は 認証とプラグイン、データ形式の経路分類は データ形式 を参照してください。
