## 4. ローカルPCで爆速操作する構成

### メインライブラリ

- **Three.js + WebGPU（または WebGL2）**
  - 大量オブジェクト・ポリゴンの描画時に CPU↔GPU オーバーヘッドを劇的削減

### データ種別ごとの最適構成

| 扱うデータ | 構成 | 理由 |
|-----------|------|------|
| 3D + 2D混在 | **Three.js (+ InstancedMesh / WebGPU)** | 同形状を1回の描画命令で描画 |
| 大容量2D線画 | **PixiJS / Canvas2D + WebGL** | 数万行ベクトルを60fps |
| ローカルGIS・点群 | **CesiumJS (+ 3D Tiles)** | ギガバイト級も部分読込み（LOD）で軽快 |

### 必須テクニック

1. **バイナリ化・構造化（最重要）**
   - JSON/XML は避ける
   - GLB / FlatBuffers / Protocol Buffers を利用
2. **Web Worker によるマルチスレッド処理**
   - UI スレッドをブロックしない
3. **OPFS / IndexedDB**
   - バイナリのまま永続化し、次回起動を瞬時に
