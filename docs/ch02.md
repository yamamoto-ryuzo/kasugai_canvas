## 2. ローカルPCで爆速操作する構成

### メインレンダラー：deck.gl + loaders.gl

- **deck.gl**
  - 2D/3D/Tiles/Buffers を同じ GPU コンテキストで一括描画
  - GeoArrow、FlatBuffers、MVT、3D Tiles を直接読み込み
  - Terrain / Mask / Clip 拡張で地形ドレープ・クリッピング・断面を GPU 処理
- **loaders.gl**
  - `@loaders.gl/arrow`, `@loaders.gl/3d-tiles` などでバイナリをゼロコピーで GPU へ

### データパイプライン

| 段階 | 技術 | 効果 |
|------|------|------|
| 読み込み | File / Blob / Box API | サーバー不要、ローカル完結 |
| 変換 | Web Worker + Arrow-JS / sql.js | UI ブロックなしで GPKG/GeoJSON → Arrow |
| 永続化 | OPFS / IndexedDB | 次回起動を即座に |
| 描画 | deck.gl GeoArrow / 3D TileLayer | VRAM ゼロコピー |

### 必須テクニック

1. **GeoArrow / FlatBuffers**
   - 数十万〜数百万点の 2D ベクトルを CPU パースなしで GPU へ
2. **Web Worker**
   - 座標変換・属性整形をバックグラウンド化
3. **OPFS / IndexedDB**
   - 巨大バイナリをブラウザ内にキャッシュ
