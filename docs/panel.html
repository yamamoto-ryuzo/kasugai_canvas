KASUGAI Canvas v6.23.0

レイヤパネル・🧰ツール — 画面の操作面（タブ・ツール単位）

画面左のレイヤパネルのタブ（レイヤ・凡例・検索・属性・カメラ・表示・情報）＋パネル下部のマルチエンジン切替、および🧰ボタンで開くツールドックに対応する機能のドキュメントです。各機能の詳細は 画面機能（V1） の該当節を参照してください。

🗺️ レイヤ

レイヤー追加・管理・一覧UI・グループ化・ベースマップ・システムレイヤ制御

🖼️ 凡例

legend: 行で凡例画像を登録・一覧表示

🔎 検索

住所検索・座標直入力・ベクトル検索（レイヤー→属性→値）

📊 属性

地物クリックで属性一覧・ドリルピック・属性テーブル（ソート・FlyTo・CSV出力・SQLフィルタ）

🎥 カメラ

cam: プリセットへワンクリック FlyTo

⛰️ 表示

地形・ドレープ・3D Tiles・効果・一般（座標形式・ミニマップ・グリッド）

ℹ️ 情報

info: 行で外部 HTML を情報タブへ表示

🎬 FLY（プレゼンテーション）

カメラワーク自動再生の FLY モード。描画ルート・シーン遷移

🧭 ポータル

portal:/view:/link:/html: 行で業務目的別のカード画面を構成。全エンジン共通 UI

🔀 マルチエンジン（engine: 切替）

パネル下部の engine: リンクで切替 — Cesium＋5互換プレイヤーで同じ .kasc を再生

🧰 ツール

レイヤパネルの🧰ボタンで開くツールドックの各サブタブです。

📏 計測

距離（測地線）・面積・方位。地形追従で3D表示時も地表値

🔲 選択・集計

矩形・ポリゴン・円で空間選択 → ポリゴン内集計・バッファ生成

✏️ 作図

ポイント・ライン・ポリゴン・注記を描いて一時レイヤー化・GeoJSON保存

📈 標高断面

折れ線の距離-標高グラフ。地形/地理院標高API

👁️ 見通し判定

観測点-対象点の可視判定と遮蔽点。可視範囲（viewshed）は Cesium のみ

📤 エクスポート

ベクターを GeoJSON/CSV/TSV/KML/FlatGeobuf/Shapefile でダウンロード

🖨️ 印刷

印刷・帳票出力

⏱️ 時系列

time=プロパティ指定の時系列レイヤー（Cesium）
