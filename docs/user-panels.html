KASUGAI Canvas v7.1.0

ユーザーパネル — パネルタブへの独自パネル・レイヤ表示の追加

1. 概要 — 2つの追加経路

KASUGAI Canvas のパネルタブへ独自のユーザーパネルを追加する経路は2系統あります。 どちらも標準のレイヤタブは変更せず、別タブとして追加されます。

経路向いている用途コード作成
WEBVIEW連携
（QGIS geo_webview → PLUGIN/custom-layer）		 QGIS のレイヤツリー構成（箇所/グループ・並び順・凡例）をそのまま Canvas の専用タブに出したい。箇所単位の属性フィルタを使いたい 不要（QGIS 側の設定→ .kasc へ自動出力）
JS作成
（自作プラグイン）		 独自の UI・集約ロジック・外部API連携など、自由なパネルを作りたい 必要（1ファイルの JS を plugin: … url= で宣言）
  • プラグインが停止・登録解除されるとパネルは自動で撤去されます（owner = pluginId で追跡）
  • 生成されたタブは data-panel/data-tab 属性を持つため、AI の汎用ブリッジ（listUiControls/controlUi）からそのまま操作できます

2. 各節

  • 4-1 WEBVIEW連携 — QGIS からカスタムレイヤ＋フィルタを出力
  • 4-2 JS作成 — 自作プラグインでパネルを追加
