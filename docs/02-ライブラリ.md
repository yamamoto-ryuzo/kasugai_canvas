## 2. ライブラリ

KASUGAI Canvas を構成する主要ライブラリについてまとめる章。基本は **CesiumJS + Three.js**。3D Tiles・DEM 上への XYZ 重ね合わせなど、地球規模の 3D 表示が必要な箇所は CesiumJS を主軸とする。

## 推奨構成：KASUGAI Canvas

| 役割 | ライブラリ | 備考 |
|------|-----------|------|
| 3D 地球・3D Tiles・DEM ドレープ・XYZ 重ね合わせ | **CesiumJS** | KASUGAI Canvas の 3D 描画の核。地球規模 LOD・地形・イメージリレイヤー・3D Tiles をネイティブに扱う |
| 点群・3DGS・高度な 3D 表現 | **Three.js** | GLB / 点群 / 3DGS エコシステム。Cesium 内のエンティティ / プリミティブと連携 |
| 大容量 2D ベクトル / タイル | **deck.gl** | オプション。2D 分析・FlatBuffers / GeoArrow / MVT 表示で活用可能 |

- **KASUGAI Canvas = CesiumJS + Three.js**。地理院標高 PNG / PLATEAU 3D Tiles 等をそのまま読み込む。
- **正式な描画方式：CesiumJS の Viewer / Scene 内でレイヤー・深度・カメラを一括管理する**。3D Tiles・DEM・XYZ・GeoJSON は CesiumJS のレイヤー / プリミティブとして配置する。

## KASUGAI Canvas で可能な表示モード

| 表示モード | 可否 | 説明 |
|-----------|------|------|
| **平面（2D 地図・図面）** | ◎ | CesiumJS `SceneMode.SCENE2D` または deck.gl / MapLibre オプション |
| **3D パース（3D モデル・点群・3DGS）** | ◎ | Cesium `Cesium3DTileset` / `Model` + Three.js 点群・3DGS レンダラー |
| **地形（DEM ドレープ）** | ◎ | Cesium `TerrainProvider` / `CesiumWorldTerrain` + `ImageryLayer` |
| **グローブ（球形地球儀）** | ◎ | CesiumJS はデフォルトで地球儀表示を扱う。グローブ / ローカル 3D 空間の切り替えが可能 |

- KASUGAI Canvas は **グローブ（球形地球）** も **ローカル 3D 空間** も扱える。
- **WGS84 / 平面直角座標等の座標系** を使い、CesiumJS の座標変換（`Cartographic`, `Cartesian3`, `Transforms`）で統一して描画する。

## データ種別別のライブラリ選択

| データ | CesiumJS | Three.js | deck.gl | 備考 |
|--------|----------|----------|---------|------|
| 3D Tiles / GLB | ◎ | ◯ | ◯ | Cesium `Cesium3DTileset` / `Model` でネイティブ表示。PLATEAU も直接読み込み |
| DEM / 標高PNG | ◎ | △ | ◯ | Cesium `TerrainProvider` / `CesiumWorldTerrain` で高精細地形。XYZ を ImageryLayer としてドレープ |
| XYZ / TMS / WMS | ◎ | △ | ◎ | Cesium `ImageryLayer` / `UrlTemplateImageryProvider` で曲面・地形にドレープ |
| GeoJSON | ◎ | △ | ◎ | Cesium `GeoJsonDataSource` / `Entity` / `Cesium3DTileset`（ベクタータイル） |
| 2D Buffers (GeoArrow/FlatBuffers) | △ | △ | ◎ | deck.gl `GeoJsonLayer（binary）` が最適。2D 分析用 |
| 2D タイル (MVT/XYZ) | ◯ | △ | ◎ | 2D 表示用途なら deck.gl `MVTLayer` / `TileLayer` |
| 点群 (PLY/LAS/EPT) | ◯ | ◯ | ◯ | Cesium `Cesium3DTileset`（pnts / 3DTiles_next）or Three.js `Points` / Potree |
| 3DGS (PLY/SPZ/Splat) | △ | ◎ | △ | Three.js 系専用レンダラー |

## CesiumJS の強力機能

| 機能 | 用途例 |
|------|--------|
| **ImageryLayer / ImageryProvider** | XYZ / TMS / WMS を地球/地形へ重ね合わせ。前後関係は `ImageryLayerCollection` で管理 |
| **TerrainProvider** | DEM / 標高PNG・CesiumWorldTerrain 等で 3D 地形を構築 |
| **Cesium3DTileset** | PLATEAU 等の大規模 3D Tiles をネイティブ LOD・カリングで描画 |
| **ClippingPlaneCollection / ClippingPlane** | 3D Tiles・点群の断面カット |
| **ClassificationPrimitive / Vector3DTilePrimitive** | 3D 地形・建物へのドレープ・クラシフィケーション |

- CesiumJS は 3D Tiles、DEM、XYZ いずれも **同じグローブ / 深度バッファ** 内で描画するため、重ね合わせの前後関係が自然に扱える。

## 点群・3DGS 用ライブラリ

| ライブラリ | 点群 (LAS/PLY/EPT) | 3DGS (PLY/SPZ/Splat) | 特徴 |
|-----------|--------------------|---------------------|------|
| **CesiumJS** | ◯ (3D Tiles pnts / 3DTiles_next) | △ (要カスタムレンダラー) | 大規模点群を地球規模で描画。3DGS は現状最適化されていない |
| **Three.js** | ◯ (`BufferGeometry`) | ◎ (`gaussian-splats-3d` / Splat Viewer) | 3DGS エコシステムが最も充実 |
| **Potree** | ◎ (専用点群レンダラー) | ❌ | 大規模点群 Web 可視化特化 |
| **PlayCanvas SuperSplat** | ❌ | ◎ | 3DGS 専用ビューアー。変換・最適化にも強い |

- **点群**：大量 PLY / LAS は **Potree 形式 / EPT / 3D Tiles（pnts）** へ変換して KASUGAI Canvas（CesiumJS / Three.js）で描画
- **3DGS**：そのまま描画には **Three.js 系の専用レンダラー** が現状最適。配信には **SPZ** 等の圧縮を検討

## CesiumJS + Three.js の連携パターン

### 正式仕様：CesiumJS 内のエンティティ / プリミティブ + Three.js 補完

- CesiumJS の `Scene` 内に `Cesium3DTileset`、`ImageryLayer`、`Entity`、`Primitive` を配置
- Three.js は Cesium の `Scene` 内に連携させるか、`Cesium.CallbackProperty` / `Cesium.Entity` 経由で位置同期
- 深度バッファ・カメラ行列・ビューポートは CesiumJS が管理。Three.js は点群・3DGS・特殊メッシュ用に補完
- フレームループは CesiumJS の `clock.onTick` または `scene.postRender` で制御

### 参考方式：オーバーレイ

- Three.js 用の `<canvas>` を下層、CesiumJS 用の `<canvas>` を上層に重ねる
- 両方を同じサイズ・カメラに揃え、CSS `pointer-events` を調整
- 実装が容易で、各エンジンの描画サイクルを独立に保てる
- プロトタイプや障害切り分けには使用できるが、深度・レイヤー順・ピッキングを統合できないため本番仕様にはしない

## 補完ライブラリ

| 用途 | ライブラリ | 説明 |
|------|-----------|------|
| 座標変換 | **proj4.js / coordsys** | 平面直角座標 ↔ WGS84 等の変換 |
| GPKG 変換 | **sql.js + WKB パーサー** | ブラウザ内で SQLite（GPKG） → Arrow/GeoJSON 変換 |
| FGDB 変換 | **ogr2ogr（サーバー or 事前変換）** | プロプライエタリ形式をブラウザ内では読みにくいため、サーバー or 事前変換で対応 |
| 点群変換 | **Potree Converter / entwine** | PLY/LAS → EPT / 3D Tiles |
