## 16. システム名アイデア

### 最推奨

- **KASUGAI Canvas**
  - 2D/3D/Tiles/Buffers を重ね合わせて描画する「空間キャンバス」
  - KASUGAI コネクタとのブランディング一貫性がある

### その他候補

| 名前 | イメージ |
|------|----------|
| KASUGAI Viewer | 直感的な軽量ビューア |
| KASUGAI View Engine / Render | レンダリングエンジン |
| KASUGAI Geo / Spatial | GIS・空間データ基盤 |
| KASUGAI Stream | CDE から VRAM へスムーズに流れる高速性 |

### KASUGAI エコシステム全体の構造

```text
KASUGAI
├── KASUGAI Canvas  (deck.gl 爆速Web描画)
│   ├── Tiles (2D/3D, PLATEAU, 地理院)
│   ├── Buffers (GeoArrow, FlatBuffers)
│   └── Extensions (ドレープ/くり抜き/断面)
├── KASUGAI Connect (Box / ローカル D&D / API 連携)
└── ...
```
