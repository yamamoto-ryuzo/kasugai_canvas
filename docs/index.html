KASUGAI Canvas v7.1.0

AIとマルチエンジンが拓く 2D/3D GIS — ローカルPC・ブラウザ完結で動作するデータ可視化システムのドキュメント

1. 📋 概要 — Canvas UI の説明

KASUGAI Canvas は、AI とマルチエンジンで拓く 2D/3D GIS です。CesiumJS + Three.js（メイン・3D）を核に、MapLibre / OpenLayers / Leaflet / GSI Maps の互換プレイヤーと試験的エンジン Navara が同じ .kasc プロジェクトを再生するマルチエンジン構成を採り、AI チャット（Gemini / OpenAI互換 の内蔵AI、GitHub Copilot・Devin・Antigravity のブリッジ連携）で地図を操作できます。Re:Earth GeoSuite と上位互換の GIS 基本機能に加え、KASUGAI 独自の FLY 機能を備えています。

画面は左パネルのタブ＋🧰ツールバーが操作の中心で、このドキュメントのナビゲーションも同じ分類（テーマ軸）で整理しています。各タブ・ツールの実装は「画面機能」、機能追加の履歴は「バージョン履歴」を参照してください。

2. 🌐💻 マルチエンジン — ブラウザ WebGIS とローカルアプリ

マルチエンジン構成（Cesium＋4互換プレイヤー＋試験的 Navara）の利用形態は2系統です。メインはインストール不要のブラウザ WebGIS（CDN エンジン × 外部ホストの .kasc を ?kasc= で再生）、フル機能が必要な場合はローカルアプリ（localhost:8510）を使います。エンジン一覧・配信構成図・?kasc= 仕様・実行時の供給元などの詳細は V6 概要 — マルチエンジン にまとめています。

DOWNLOAD: インストーラー ZIP（推奨） DOWNLOAD: ポータブル ZIP

導入・利用手順は ブラウザ WebGIS ガイド・ローカルアプリのガイド を参照してください。

3. 🗺️ QGIS連携 — プロジェクトをそのまま Web で再現

V7 のメインテーマです。QGIS プラグイン geo_webview がレイヤーツリー・スタイル（.qml）・表示状態・テーマ・ブックマークを .kasc + canvas_data/ へエクスポートし、ブラウザ WebGIS（?kasc=）またはローカルアプリでそのまま再生します。レイヤーフィルタ（subsetString）は where= として引き継がれ、同期系統は2系統あります。

連携面内容
Live 双方向同期live: 行入り .kasc で有効化。カメラ追従・QGIS 選択表示・QGIS 描画オーバーレイ・レイヤーのオンデマンド追加・表示/フィルタ/テーマの書き戻し（レイヤ一覧の QGIS Live パネル）
AI / MCP 操作起動時に稼働中の QGIS Live Driver セッションを自動検出して MCP 接続し、qgis_pyeval・qgis_bridge_call でレイヤ制御・kasugaiExport・Processing 解析まで AI から実行（書き込み系は公開ゲート対象）

詳細は V7 概要 — QGIS連携・QGIS連携（技術詳細・未対応 Issue） を参照してください。

4. 🤖 AI — API 直通とブリッジ経由

AI チャットはどちらの利用形態でも使えます。接続系統は2系統で、プロバイダ名の接頭辞【API】/【ブリッジ】がそのまま系統を示します。メインは公式 API へブラウザから直接繋ぐ内蔵AI、既存の AI 契約や自作エージェントを繋ぐ場合はブリッジ経由を使います。

【API】内蔵AI（メイン）【ブリッジ】外部エージェント
プロバイダ Gemini・OpenAI互換（GitHub Models・OpenAI・Azure OpenAI・Ollama 等） GitHub Copilot・Devin（devin acp）・Antigravity・汎用 ACP プロバイダ（provider:"acp"、ACP 対応の任意エージェント CLI）・外部エージェント（汎用 /agent エンドポイント）
接続経路 ブラウザ → 公式 API へ直接（BYO キー）。Cloudflare/Cloud Run では /api/gemini キー隠蔽プロキシでキーレス利用も可 チャット → POST /agent → ブリッジハブ → 各 CLI（copilot / devin acp / agy / ACP 対応 CLI）。要各 CLI・本人認証（ACP はブラウザ認証または API キー）
【WebGIS】ブラウザ WebGIS ○（BYO キー / サーバーキー） ○（同一 PC の bridge-hub :8511 を検出。CDN の download/bridge-hub.exe を実行すれば自己インストール。exe＋README の一式は download/bridge-hub.zip）
【アプリ】ローカルアプリ ○ ○（インストール済みの bridge-hub :8511 を自動起動。ハブは CDN 配布版と同一の1本）
ツール実行方式 function calling ループ — ツール結果を見て複数往復で判断（多段操作に強い） 単発キュー — 応答の actions を一括実行

どちらの系統でもチャット UI・地図操作・runCode サンドボックス・MCP データソース（Box・QGIS 等）・AI プラグイン生成は共通です。ハブはアプリ版・ブラウザ WebGIS 共通の bridge-hub.exe 1本（127.0.0.1:8511）に集約しており、フロントは /health で検出して接続するため、CDN 経由のブラウザ WebGIS からもブリッジ系プロバイダが選べます。逆方向の「外部 → ブラウザを操る」はローカルアプリ本体 :8510 の /api/command 経路です。

設定手順は 【API】内蔵AI・【ブリッジ】外部エージェント連携（接続方式ごとの規約判断もこちら）、81ツール宣言（環境・エンジンで絞り込み）の引数・提供条件は AI ツール仕様 を参照してください。
