KASUGAI Canvas v6.2.0

ローカルPC・ブラウザ完結で動作する 2D/3D データ可視化システムのドキュメント

📋 概要

KASUGAI Canvas は、CesiumJS + Three.js を核とした 2D/3D データ可視化システムです。Re:Earth GeoSuite と上位互換の GIS 基本機能に加え、KASUGAI 独自の FLY 機能・AIチャット（Gemini / OpenAI互換 / GitHub Copilot・Devin・Antigravity（アプリ版）連携）を備えています。

v3.4.2 以降、地図タイル・検索・レイヤー取得は CesiumJS が直接行い、Rust サーバーはバージョン管理・シャットダウン・ヘルスチェック API のみ提供します。

ローカルアプリ kasugai_canvas.exe

インストールして使うフル機能版です（QGIS連携・ファイル保存・rclone クラウド連携・AIブリッジなど、localhost:8510 で動作）。配布物は download/ フォルダから直接ダウンロードできます。インストーラー版を推奨します — .kasc ファイルのダブルクリック起動（拡張子の関連付け＝外部プロジェクト登録）はインストーラー版でのみ利用できます。

公開デモ（ブラウザ WebGIS の実例）は ブラウザ WebGIS ページにまとめています。

🔗 連携構成図 — どこで動くか

KASUGAI Canvas は エンジン（プレイヤー本体）とデータ（.kasc + DATA/）が分離した設計です。開発の起点は kasugai_canvas リポジトリの web/（エンジン正本）で、そこから GitHub Pages CDN（kasugai-canvas-web） と 配布 ZIP（ローカルアプリ） の2経路で発行されます。メインの使い方は、CDN が配信するエンジンに静的ホスト上の .kasc を ?kasc= で指定して開く サーバレスな WebGIS です（インストール不要）。

再生 URL …/<stage>/<engine>/?kasc=<.kascのURL> の意味:

要素値意味
<stage> stable（既定）/ unstable / latest CDN の配信チャンネル。stable=安定版・unstable=開発版・latest=stable へのリダイレクト
<engine> cesium / maplibre / openlayers / leaflet / gsimaps 再生に使う描画エンジン。cesium がメイン（3D・フル機能）、他は同じ .kasc を読む互換プレイヤー
?kasc= .kasc ファイルの URL（要 URL エンコード） DATA/ 等の相対参照は .kasc のある URL 基準で解決されるため、.kasc と DATA/ は同じフォルダに置く

静的ホストへ .kasc+DATA/ だけを置く通常の WebGIS 配信では、エンジンは常に CDN（kasugai-canvas-web）から読み込まれます。機能面ではローカルアプリだけがフル機能（QGIS連携・ファイル保存・rclone・AIブリッジ）を持ち、CDN 経由はブラウザ閲覧中心です。公開デモはいずれもこの WebGIS の実例で、Cloudflare Pages/Workers・Cloud Run 版は web/ を自前配信し認証・/api/* を付加した構成です（基本の配布経路は CDN + 配布ZIP の2系統）。データの配信元は静的ホストのほか、QGIS 側の geo_webview 内蔵サーバー（localhost:8089 /export-data/）からも読めます（自分の PC 上のみ有効）。詳細は kasugai-canvas-web ガイド を参照してください。
