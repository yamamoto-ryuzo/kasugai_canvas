1-2 凡例 — レイヤパネルの「凡例」タブ

使い方

🖼️ 凡例表示

legend: 行で凡例画像の URL を指定すると Legend タブに一覧表示します。複数行で複数の凡例を登録できます。凡例画像は静的ファイル・外部 URL・ローカル DATA/ 内ファイルのいずれも使えます。

legend: 凡例 | https://example.com/legend.png
legend: 凡例2 | DATA/legend2.png

QGIS スタイル（style= の .qml や GPKG 埋め込みスタイル）が適用されたベクターレイヤーは、QML 由来の凡例スウォッチと条件別の表示切替も凡例タブに表示されます。

凡例画像の下には「凡例を表示するレイヤ」セレクタも表示されます。凡例を持つベクターレイヤー（QML スタイル適用レイヤー・既定スタイルのベクターレイヤー）をドロップダウンで切り替えると、そのレイヤーの凡例スウォッチ一覧を確認できます。選択中レイヤは表示のたびに保持され、レイヤ一覧でのシンボル表示/非表示の切替もここに反映されます。

🔗 QGIS 連携（geo_webview）— 高度な設定は QGIS に任せる

凡例・スタイル・フィルタといった高度な設定は QGIS 側に任せるのがこの連携の考え方です。QGIS のレイヤースタイル（.qml）・凡例ノードの並び・レイヤーフィルタは、QGIS プラグイン geo_webview のエクスポート（.kasc＋DATA/）でそのまま Canvas に再現されます — Canvas 側で同等の設定 UI を持つ必要はありません。

  • geo_webview（QGIS プラグイン）
    リポジトリ: https://github.com/yamamoto-ryuzo/qgis_live_harness/tree/master/qgis-plugin/geo_webview
    ドキュメント: https://github.com/yamamoto-ryuzo/qgis_live_harness/tree/master/qgis-plugin/geo_webview/docs
  • QML スタイル（style=） — 分類・ルールベース・ラベル等の高度なスタイルは QGIS のスタイル設定で作成し、style= の .qml として凡例スウォッチ・条件別表示まで再現: スタイル（.qml）の再現（QGIS連携の実装範囲）・ 6-2 インスペクター（style= の書式）
  • フィルター（where=） — 絞り込み条件は QGIS のクエリビルダ（レイヤーフィルタ / subsetString）で設定し、where= として引き継ぎ。条件別の凡例表示にも反映: V7: QGIS連携 — where= フィルタ引継ぎ・ レイヤー → .kasc 行の対応・ 1-4 属性 — フィルター

設定方法（.kasc）

legend: 凡例 | https://example.com/legend.png
legend: 凡例2 | DATA/legend2.png
legendnode: 凡例ノード順・ラベル・表示名（直前のレイヤー行に適用）
  • ベクター行の style=QMLファイルURL で QGIS スタイルを適用すると、QML 由来の凡例スウォッチと条件別の表示切替が凡例タブに出ます（再現範囲は スタイル（.qml）の再現）
  • geo_webview（QGIS プラグイン）のエクスポートでは凡例画像・凡例ノードが自動出力されます（QGIS のレイヤーフィルタは where= へ引き継がれ、フィルタ条件ごとの凡例表示に反映されます）
