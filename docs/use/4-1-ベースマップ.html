4-1 ベースマップ選択 — 画面右上の背景地図セレクト

使い方

🗺️ ベースマップ選択

画面右上のセレクトボックスで OpenStreetMap / 地理院地図（淡色・標準・写真・陰影）/ Google Maps（API キー設定時のみ表示）の背景地図を切り替えます。選択はプロジェクトとブラウザ（localStorage）に保存され、エンジン切替時も引き継がれます。

base: 行（base: osm・base: gsi_std・base: google 等）で初期ベースマップを指定でき、base: none で背景地図なし（単色背景）にもできます。basemap: 名前 | XYZ URL 行でカスタムタイルをセレクトへ追加も可能です。レイヤー行の xyz:・base: で指定したタイルはこのセレクトと独立して読み込まれます。

管理 → Google Maps で Maps JavaScript API キーを登録すると Google Maps が選択肢に現れ、同キーで Geocoding / Places も使えます。タイルは Google の規約上 MapTypeId 直接指定ではなく、Maps API の表示レイヤ（vector/raster）を背景に使います。Google はセレクトに残してあり、未登録時に選ぶと「API キーが必要」と案内します。

設定方法（.kasc）

base: 地理院タイル 標準地図 | https://cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png | 出典：国土地理院 | maxZoom=18
base: 写真 | https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg | off
base: 表示名 | transparent |   （ベースマップ透明＝地表透明を初期選択）
base: 表示名 | none |          （ベースマップなしを初期選択）
xyz: 重ねるタイル | https://example.com/{z}/{x}/{y}.png | opacity=0.7
  • base: 行がベースマップセレクトの選択肢になります（先頭が既定・| off で非初期選択）。タイトルの「グループ/名前」はセレクト内の折りたたみグループになります
  • xyz: 行はベースマップとは独立したタイルレイヤーとして重なります
  • Google Maps を使うには管理 ⚙ → Google Maps で API キーを登録します（6-4 Google Maps）
