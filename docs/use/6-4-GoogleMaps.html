6-4 Google Maps — Maps API キーとハイブリッド検索

「Google Maps」カテゴリでは Google Maps Platform の API キーを登録し、ベースマップとジオコーディング・Places 検索を有効化します。

使い方

機能

  • ベースマップ — キーを登録すると 4-1 ベースマップ セレクトに Google Maps が現れ、Maps JavaScript API の表示レイヤを背景に使います
  • Geocoding / Places — 1-3 検索 でのハイブリッド検索（地理院検索 + Google 検索）や Places API による施設検索に利用します
  • 登録方法 — キーはブラウザの localStorage に保存され、.kasc には含まれません。公開 URL で共有するプロジェクトでも、各ユーザーのブラウザで個別に登録するだけで使えます

設定方法

  1. Google Cloud Console で Maps JavaScript API・Geocoding API・Places API を有効化し API キーを発行
  2. 管理 ⚙ → Google Maps の入力欄にキーを貼り付けて保存（ブラウザの localStorage に保存・.kasc には含まれません）
  3. ベースマップセレクトに Google Maps が現れ、検索で Geocoding / Places のハイブリッド検索が使えます
