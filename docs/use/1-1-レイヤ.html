1-1 レイヤ — レイヤパネルの「レイヤ」タブ

画面左パネルの「レイヤ」タブは、読み込んだレイヤーの一覧・表示切替・並べ替え・グループ化を行う操作面です。レイヤーの定義自体は .kasc（インスペクター）に行単位で記述します。

使い方

➕ レイヤー追加・管理

XYZ タイル・3D Tiles・GeoJSON などを URL 指定で追加できます。ローカルサーバー版では DATA/ 内ファイルや cloud: スキームのクラウド上ファイルもレイヤーとして読み込めます。追加したレイヤーは Layers パネルで表示切替・並べ替えでき、設定（.kasc）に永続化されます。

📑 レイヤー一覧UI

読み込んだレイヤーを一覧し、チェックで表示切替、ドラッグ＆ドロップで並び替えができます。各行の 📍 ボタンでレイヤー全体の範囲へフォーカス（FlyTo）します。並べ替えた順序は ImageryLayerCollection の lower/raise や DataSource の index に反映され、表示切替や排他グループ動作は並べ替え後も維持されます。

ベクターレイヤーは行の ⏷ ボタンで絞り込み条件を対話的に変更できます。Cesium では全ベクター型が対象で、属性一覧の「SQL」ボタンと同じダイアログが開きます（sql:/ogrsql: はクエリ全文、それ以外は WHERE 式を where= として適用。変更は .kasc 行へ書き戻され、描画と属性一覧に反映されます）。他エンジンはクエリ系（gpkg:/duckdb:/sql:/ogrsql:）のみ対象です。エンジンで再現できないレイヤ型の行は、一覧から消さずグレーアウト行（チェック無効・半透明・ツールチップ「このエンジン未対応の形式」）として残ります。

📂 レイヤーグループ化

レイヤー名に / を含めるとフォルダのようなグループに、// を含めると排他グループ（同時に1つだけ表示・ラジオボタン的動作）になります。地物カテゴリの切替や対比表示に使えます。排他グループのメンバー行はラジオで、選択済みを再クリックすると OFF にできます。

🔧 システムレイヤ制御（layer: 行）

layer: 行で既存レイヤー名を指定し、表示/非表示を初期状態として制御します。プロジェクトを開いた時点で特定レイヤーだけを見せたい場合に使います。非表示にされたベクターレイヤーはロード自体もスキップされ、表示ON・検索・フィルター変更のタイミングで初めて取得されます。

設定方法（.kasc）

レイヤーの定義・初期表示・絞り込みは .kasc（管理 ⚙ → プロジェクト → インスペクター）の行で設定します。

種類:タイトル|URL|出典|オプション名=値|on/off
  • xyz: XYZ/TMS タイル / wms:・wmts: OGC タイル / 3dtiles: 3D Tiles
  • geojson:・geoparquet:・flatgeobuf:・kml:・wfs:・shp:・csv: 全件読み込みベクター
  • gpkg: GeoPackage / duckdb:・sql:・ogrsql: SQL 絞り込み（既定で表示範囲連動 bbox=auto）
  • image: 画像オーバーレイ / geotiff: COG ラスタ / model: 3D モデル / mvt:・pmtiles: ベクトルタイル
geojson: 東京都/行政区域 | DATA/kuiki.geojson | on
3dtiles: 建築物（LOD1） | https://example.com/tileset.json | off
gpkg: 河川 | DATA/rivers.gpkg | table=rivers | where=延長 > 100
duckdb: 施設 | https://example.com/facilities.parquet | limit=1000
  • タイトルの / = グループ、// = 排他グループ（ラジオ動作）。on/off で初期表示を指定
  • 共通オプション: where=（行の最終オプション・描画を絞り込み）・opacity=・render=primitive|entity・style=QML・cluster=on・heat=on・minScale=/maxScale=（縮尺表示）・attr=出典
  • layer: レイヤー名 | off — 既存レイヤーの初期表示を制御
