2-7 印刷 — ツールドックの印刷・帳票出力

使い方

🖨️ 印刷・帳票出力

ツールドック（レイヤパネルの🧰ボタンで開く）の「エクスポート」にある 印刷 ボタンで印刷ダイアログを開き、表示中の地図にタイトル・凡例・縮尺バー・方位記号・出典・日付を付けた帳票（A4/A3・縦横・150/300dpi）を生成します。「印刷」はブラウザの印刷ダイアログへ（PDF 保存も可能）、「PNG保存」は合成画像をダウンロードします。

「範囲プレビュー」を有効にすると用紙サイズの枠が地図上に表示され、ドラッグで範囲移動・縮尺入力で出力範囲を事前調整できます（Cesium/MapLibre/OpenLayers/Leaflet 共通）。

QGIS(geo_webview)の HTTP サーバーが検出できた場合のみ「QGIS レイアウトPDF」セクションが表示され、QGIS の印刷レイアウトをそのまま PDF 出力できます（QGIS 側の /layouts・/layout-pdf エンドポイントを利用）。タイルが CORS 未対応で地図画像を取得できない場合は、地図なしの帳票にフォールバックします。

設定方法

このツールは .kasc の設定行を持ちません（UI 操作のみです）。関連するレイヤー設定は 6-2 インスペクター を参照してください。
