6-3 AI — 管理画面の AI 設定カテゴリ

「AI」カテゴリは KASUGAI Canvas の AI 連携の統括設定です。内蔵 AI（ブラウザ内 function calling）と外部エージェント（ChatGPT / Claude / MCP 経由）の両方をここから設定します。

使い方

設定項目

  • 内蔵 AI — 使用する AI バックエンド（Gemini / OpenAI / Azure OpenAI / GitHub Models など）と API キーの登録。5-1 内蔵 AI（AiPanel） の設定をここで行います
  • 外部エージェント — Claude Desktop / ChatGPT との接続設定（MCP・カスタムGPT・アクションURL）。5-2 外部エージェント連携
  • AI ツール宣言 — AI へ公開するツール数・カテゴリの絞り込み。5-3 AI ツール仕様
  • ブリッジハブ — 外部エージェントとの常駐接続ハブ。5-4 ブリッジハブ

設定方法

各設定は管理 ⚙ → AI カテゴリ内のフォームから行い、API キーやプロバイダ選択はブラウザ（localStorage）へ保存されます（.kasc には含まれません）。

  • 内蔵 AI のプロバイダ・API キー・カスタム指示・AI プラグイン → 5-1 内蔵 AI
  • 外部エージェント（MCP・カスタムGPT）の接続先 → 5-2 外部エージェント・5-4 ブリッジハブ
  • AI へ公開するツールの絞り込み・ステップ上限 → 5-3 AI ツール仕様
