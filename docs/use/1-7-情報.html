1-7 情報 — レイヤパネルの「情報」タブ

使い方

ℹ️ Info 表示

info: 行で指定した外部 HTML を Info タブに表示します。スクリプト等はサニタイズされ、プロジェクト説明・参考資料・凡例ドキュメントの埋め込みに使えます。

info: https://example.com/project-info.html
info: DATA/readme.html

埋め込まれた HTML 内の .tab-button＋.tab-content の組は、パネル内サブタブとして自動配線されます（1-9 ポータル のカスタム HTML と同じ規則）。

⚠️ 未対応行の警告

開いているエンジンで再現できない行タイプが .kasc に含まれる場合、情報タブに「未対応行」の警告が表示されます。対象行はレイヤ一覧でもグレーアウト表示になります（1-10 マルチエンジン のエンジン別対応範囲を参照）。

設定方法（.kasc）

info: https://example.com/project-info.html
info: DATA/readme.html
title: 春日井市 防災マップ    （パネル左上とブラウザタブのタイトルを差し替え）
  • 埋め込み HTML はサニタイズされます（script・on* 属性は除去。詳細は セキュリティ対策）
  • 未対応行の警告はエンジン側で自動判定されるため設定は不要です
