KASUGAI Canvas v6.23.0

6-6 その他 — 言語・自動更新・データ取得プロキシ・ブラウザ連携

使い方

🌐 言語

UI の言語を日本語 / English から切り替えます。選択はブラウザに保存され、対応している文字列は翻訳テーブル経由で表示されます。

🔄 自動更新

ローカルアプリ版では起動時に download/latest.json を参照して新版を検出し、自動更新を行います（既定 ON）。開発中や意図的に旧版を使いたい場合は OFF にできます。

🔀 データ取得プロキシ

ローカルアプリ版では /api/fetch?url= 経由で外部 URL をプロキシ取得し、CORS で取れないリソース（外部タイル・GeoJSON 等）を読み込めるようにします。静的ホスト版（CDN）では直接 URL 指定のみです。

🔌 ブラウザ連携

ローカルアプリ版では kasugai: プロトコルハンドラで外部アプリ・リンクからプロジェクトを起動し、別アプリで開くボタン等と連携します。ブラウザ WebGIS（静的ホスト版）ではこの連携はありません。

設定方法

  • 言語 — 管理 ⚙ → その他 の言語セレクト（日本語/English 等8言語）。選択はブラウザに保存
  • 自動更新 — 管理 ⚙ → その他 のトグル（ローカルアプリ版のみ。起動時に download/latest.json を参照）
  • データ取得プロキシ — ローカルサーバーの /api/fetch?url=。レイヤー行の proxy=on/proxy=off で経路を指定（6-2 インスペクター）
  • ブラウザ連携 — kasugai: プロトコルハンドラはアプリインストーラーが OS へ登録（4-2 別アプリで開く）
