## 用語集

| 用語 | 意味 |
|------|------|
| **WebGL / WebGPU** | ブラウザで GPU を使った描画 API |
| **Three.js** | WebGL ベースの3Dライブラリ |
| **deck.gl** | Uber 発の大規模データ可視化ライブラリ |
| **loaders.gl** | 各種地理空間・3Dフォーマットのローダー群 |
| **FlatBuffers** | Google 製の高速バイナリシリアライズフォーマット |
| **GeoArrow** | 地理空間データ向け Apache Arrow 標準 |
| **MVT** | Mapbox Vector Tile（Protocol Buffers ベース） |
| **GPKG** | GeoPackage。SQLite ベースの GIS ファイル |
| **GLB/glTF** | 3D モデルの標準バイナリフォーマット |
| **3D Tiles** | 広域3Dデータをタイル化・LOD 配信する OGC 標準 |
| **ドレープ** | 2Dデータを3D地形に沿って貼り付ける処理 |
| **クリッピング** | 特定範囲のみを切り抜く処理 |
