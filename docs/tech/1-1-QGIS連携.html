1. 概要 — QGIS と geo_webview（WEBVIEW）

QGIS（キュージーアイエス）は、無償のオープンソース・デスクトップ GIS ソフトウェアです（qgis.org）。地図データ（ベクター・ラスタ・3D）の表示・作成・編集・解析・スタイル設計をフル機能で行え、官庁・自治体・建設・研究機関で広く使われている業界標準のツールです。QGIS の作業単位が「プロジェクト」（レイヤーの組合せ＋スタイル＋表示設定）です。

KASUGAI Canvas は「表示・配信」専用の設計で、地図プロジェクト自体の作成・編集は行いません。その役割を担うのが QGIS です — QGIS で作ったプロジェクトを、そのまま Canvas の高速 2D/3D エンジン（Cesium 等）で再現・配信するのが QGIS連携の目的です。Canvas ユーザーが QGIS を使うのは、「地図の中身を作る・直す」ためです。

geo_webview（WEBVIEW）はその橋渡しとなる QGIS プラグインです。QGIS 内部で動作し、プロジェクトの .kasc + canvas_data/ へのエクスポート・GET /live/kasc オンデマンド生成・ライブ双方向同期・Canvas からの書き戻し受付をすべて QGIS 側で担います。QGIS連携を使う = QGIS に geo_webview を導入すること、これが唯一の前提です。

導入の流れ

  1. QGIS をインストール — 公式サイトから。GIS データの編集・プロジェクト作成・スタイル（.qml）作成はすべて QGIS 側で行います
  2. geo_webview（WEBVIEW）を導入 — リポジトリの配布物を QGIS のプラグイン管理からインストール（使い方は プラグインドキュメント / SPEC.md）
  3. 連携を開始 — パネルの「KASUGAI」ボタンでプロジェクトを Web 化（→ 下記1）、「Live」タブの「Open Canvas Live View」で 3DVIEW 化（→ 下記2）

連携の成果は3つ — ① プロジェクトWeb化: .kasc + canvas_data/ をエクスポートして WebGIS として配信。② 3DVIEW化: /live/kasc + live: 行で編集差分・制御を継続同期し、Canvas を QGIS の3Dビューとして運用。③ 双方向オーサリング: Canvas → QGIS の復路（書き戻し・地物投入・URL 取込）。①②はどちらも同じ .kasc 形式による「再現」の輸送経路です。
