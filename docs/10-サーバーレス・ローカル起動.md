## 10. サーバーレス・ローカル起動

HTTP サーバーが使えなくても deck.gl はクライアント完結で動作可能。

### データ読み込み手法

| 方法 | 概要 |
|------|------|
| **File / Blob / ArrayBuffer 直読** | ドラッグ&ドロップ or ファイル選択。HTTP(fetch)不要、CORSなし |
| **OPFS / IndexedDB** | ブラウザ内にバイナリをキャッシュ。オフラインでも爆速起動 |
| **PWA (Service Worker)** | 内部で HTTP リクエストを横取りし、ローカル/Zip から返す |
| **Tauri / Electron** | デスクトップ化し、`app://data/...` スキームで安全読込み |

### KASUGAI × Box 構成

- **Box を CDE（保存領域）**、**KASUGAI を可視化エンジン**
- Box API / Direct Download Link から取得したバイナリを、ブラウザ内でそのまま deck.gl へゼロコピー転送
- オンライン時は Box から取得、オフライン時は OPFS / ローカルファイルで独立動作
