KASUGAI Canvas v7.1.0

エンジン — 6つの地図画面の特徴と使い分け

1. 概要

KASUGAI Canvas は、同じプロジェクトを6種類の地図画面（エンジン）で開くことができます。 画面パネルの下にある「engine:」のリンクから、見ている場所や内容をそのままに別のエンジンへ切り替えられます。 それぞれ得意なことが違うので、目的に合わせて使い分けてください。

2. エンジン別の特徴

🌐 Cesium（メイン・既定）

一番いろんな表現で表示できる、全部入りのエンジン。地図を立体的（3D）に見たり、地形の起伏や建物の立体モデルを表示したり、プレゼンのように視点を動かしたりできます。AI 操作や追加機能にもすべて対応。迷ったらこのエンジンを使ってください。

🗺 MapLibre（サクサク 2D）

データが多くても軽快に動く 2D エンジン。たくさんの情報を載せた地図でもストレスなく拡大・縮小・移動でき、地図を回転させたり少し傾けて立体的に見せることもできます。

🧭 OpenLayers（表示が多様な 2D）

いろいろな種類の地図・データを幅広く表示できる堅実な 2D エンジン。外部の地図サービスとの相性が良く、パソコンの性能をあまり選ばずに動作します。

🍃 Leaflet（とにかく軽い 2D）

最も軽いエンジン。古いパソコンやブラウザでも開けるため、「相手の環境が分からないけど確実に見てほしい」という共有用に向いています。

🇯🇵 GSI Maps（地理院地図・調整中）

国土地理院の「地理院地図」と同じ画面・同じ操作感でプロジェクトを開けるエンジン。使い慣れた地理院地図のレイヤー選択をそのまま使えます。現在調整中です。

✨ Navara（きれいな 3D・試験的）

写真のようにリアルな 3D 表示が特徴のエンジン。空や太陽の光まで再現した美しい見た目で、プレゼンの見せ方を重視したいときに。試験的なため、使えない機能もあります。

3. 使い分けの目安

こんなときはおすすめ
立体的に見たい・プレゼンしたいcesium
データ量が多い地図をサクサク見たいmaplibre
様々な種類の地図を幅広く表示したいopenlayers
古いパソコンでも確実に開けるようにしたいleaflet
地理院地図そのままの画面で見たいgsimaps
見た目がきれいな 3D を試したいnavara
