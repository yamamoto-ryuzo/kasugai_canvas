KASUGAI Canvas v7.2.0

UI カスタマイズ — ui.config.json でパネル機能の表示/非表示・初期値を配布単位で制御

UI カスタマイズ管理画面
http://127.0.0.1:8510/admin/ui-config-admin.html

ブラウザで開くと、実際のエンジン画面をプレビューしながら画面構成を ON/OFF してカスタマイズ設定を作成できます。ローカルアプリでは「サーバーに保存」で直接書き込み、CDN・静的ホストでは「ブラウザに保存」（そのブラウザでの表示に即適用）か「ダウンロード」/「コピー」で ui.config.json を各エンジンフォルダへ配置します。詳細は 4. UI カスタマイズ管理画面 を参照。

1. 概要 — 何が制御できるか

ui.config.json を各エンジンの index.html と同じフォルダに置くだけで、 その配布先の KASUGAI Canvas の画面構成を、コードを変更せずにカスタマイズできます。 納品先・用途ごとに別のファイルを用意すれば、同じソフトを配布単位で別の顔にできます。

  • 表示/非表示: パネルタブ（レイヤ/凡例/検索/属性/カメラ/表示/情報）・ツールドックの各ツール・管理ウィンドウの項目・AIチャット・ポータル・エンジン切替・個別ボタンまで、機能単位で ON/OFF
  • 初期値: チェックボックス・セレクト・数値などコントロールの起動時の値（例: 地形 OFF・ミニマップ ON・DEM ソースの選択）
  • 起動タブ: 起動時に最初に開くタブ（例: 検索）
  • ヘルプ先: パネル右上の ? ボタンのリンク先（社内手順書等への差し替え）

用途例: 納品用に「検索・属性タブを隠す」「AI チャットを出さない」「地形の初期値を OFF にする」 「ミニマップを最初から表示する」「試験的エンジンへのリンクを消す」などの個別カスタマイズ。

2. 設定の作り方と配置（手順）

2-1. UI カスタマイズ管理画面で作る（推奨）

http://127.0.0.1:8510/admin/ui-config-admin.html を開き、実エンジンのプレビュー上でチェックボックスを ON/OFF するだけで設定を作れます （書き方を覚える必要はありません。CDN ホスト版 <channel>/admin/ui-config-admin.html でも同じ手順で作成できます）。

  1. エンジンを選び、プレビュー内の各タブ・パネル・部品のチェックで非表示にする機能を OFF
  2. プレビュー内のコントロールを操作すると初期値（defaults）として記録
  3. 「生成して反映」で ui.config.json を出力
  4. ローカルアプリなら「サーバーに保存」でそのまま書き込み完了。CDN・静的ホストでは「ブラウザに保存」（そのブラウザで開くエンジンに適用）か「ダウンロード」/「コピー」して配置

操作の詳細は 4. UI カスタマイズ管理画面 を参照してください。

2-2. 手書きで作る

web/cesium/ui.config.sample.json をコピーして ui.config.json にリネームし、 コメントを見ながら編集します（//・/* */ コメントと末尾カンマが使えます）。 書式は 3. 設定ファイルの形式 を参照。

2-3. 配置と反映

  • 配置先: web/<engine>/ui.config.json — 対象エンジンの index.html と同じフォルダ（cesium / maplibre / openlayers / leaflet / gsimaps / navara それぞれ別ファイル）
  • ローカルアプリ: UI カスタマイズ管理画面の「サーバーに保存」で直接書き込むか、ファイルを手配置
  • CDN 公開: web/ 内の ui.config.json は tools/publish_cdn.py でそのまま配信されます。ローカルで作った設定を公開したい場合は publish のみで反映されます
  • ブラウザ保存（localStorage）: 管理画面の「ブラウザに保存」は kasugai.ui-config.<配置dir> キーへ書き込み、同じ配信元のエンジン起動時に ui.config.json ファイルより優先して適用されます。CDN 公開後でもブラウザごとに画面構成を修正できます（配布物自体は変わりません。元に戻すには「ブラウザ保存を削除」）
  • 反映タイミング: 起動時に1回だけ読み込まれます。変更後はページ再読み込みで反映
  • ファイルが無い場合（404）は何もしません。既定挙動のまま起動します

3. 設定ファイルの形式

{
  // 機能の非表示。機能名または CSS セレクタで指定
  "hide": [
    "attr",            // 属性タブ（タブとパネルの両方が隠れる）
    "tools:los",       // ツールドックの「見通し判定」
    "manage:gmaps",    // 管理ウィンドウの「Google Maps」
    "chat",            // AI チャットパネル
    "#help-open"       // セレクタ直指定（ヘルプ ? ボタン）
  ],
  // コントロールの初期値（要素 id → 値）
  "defaults": {
    "terrain-toggle": false,   // 地形(DEM表示)を初期 OFF
    "dem-source": "gsi5m",     // DEM ソースの初期選択
    "display-minimap": true,   // ミニマップを初期 ON
    "effect-fog": false        // 霧を初期 OFF
  },
  // 起動時に開くタブ（省略時は従来の既定タブ）
  "open": "search"
}

3-1. hide — 機能の非表示

タブ系の機能を隠すと対応パネルもまとめて隠れます。非表示にしたタブがアクティブだった場合は、 先頭の表示タブへ自動で繰り上がります。適用は起動時の1回のみで、後から動的に生成される要素は対象外です。

指定方法対象例
名前のみパネルタブ＋同名のタブ/要素layers legend search attr camera display info
tools:<名>ツールドックのツールmeasure spatial draw profile los export print time
display:<名>表示タブ内サブタブterrain drape tiles effects general
manage:<名>管理ウィンドウ大分類project ai gmaps app other
managesub:<名>管理内サブタブgemini datasource plugin ai-install 等
固定名タブ規約に載らない部品chat（AIチャット） portal（ポータル） engines（エンジン切替）
engine:<名>エンジン切替バーの個別リンクengine:navara（navara リンクだけ隠す。engines:<名> でも可）
要素 id / CSS セレクタ任意の UI 要素time-bar tools-dock share-copy screenshot-button manage-open help-open project-select "#search-provider" ".control-panel"

要素 id は開発者ツールや index.html の id="…" で確認できます。 セレクタ記法（#・.・[・空白・> で始まる文字列）はそのまま querySelectorAll へ渡されます。

3-2. defaults — コントロールの初期値

"要素 id": 値 の対で指定します。checkbox は true/false、 select・テキスト・数値・スライダーはその値を設定します。 設定値はユーザー操作と同じイベント（input → change）で適用されるため、 内部状態や再描画へ正しく反映されます。指定できる主な id は web/cesium/ui.config.sample.json のコメント一覧を参照してください。

  • 存在しない id・値のない選択肢は警告を出してスキップします

3-3. open — 起動時に開くタブ

hide と同じ機能名で指定します（例: "open": "search"）。 省略時は従来通り先頭タブ（レイヤ）が開きます。

3-4. helpUrl — ヘルプボタンのリンク先

パネル右上の ?（ヘルプ）ボタンのリンク先 URL を上書きします（例: 社内独自の手順書へ差し替え）。 省略時は既定の公式ヘルプのままです。ボタン自体を消したい場合は hide に "#help-open" を指定してください。

4. UI カスタマイズ管理画面

http://127.0.0.1:8510/admin/ui-config-admin.html をブラウザで開くと、実際のエンジンをそのまま表示したプレビュー上でカスタマイズできます。 CDN ホスト版にも <channel>/admin/ui-config-admin.html として配信されており、 どちらも画面構成の ON/OFF・JSON 生成は同じ手順で行えます。

  • 各タブ・パネル・部品の右上に表示されるチェックボックスで hide を ON/OFF できます。OFF はグレー表示（再チェックでその場復帰）で、ツールバーやベースマップ行のボタン単位、エンジン切替バーのリンク単位まで指定できます。「実際に隠す」モードで本番の見え方も確認できます
  • プレビュー内のコントロール（チェック・選択・数値）を実際に操作すると、その値が defaults の初期値として記録されます。値系コントロールは「コントロール一覧から手動追加」から直接入力もできます
  • 「現在のタブ」ボタンでプレビュー表示中のタブを open（起動時タブ）に、「ヘルプURL」入力欄で helpUrl（? ボタンのリンク先）を設定できます
  • 「サーバーに保存」で POST /api/ui-config/{engine} 経由の直接書き込み、「設定を削除」で DELETE が実行できます（ローカルアプリのみ。/api はローカルサーバーにのみ存在します）
  • 「ブラウザに保存」は localStorage へ書き込み、同じ配信元のエンジン起動時にファイルより優先して適用されます（CDN でも有効。ブラウザごとの上書きなので他の利用者には影響しません）。「ブラウザ保存を削除」で解除できます
  • 公開範囲について: この画面は web/admin/ 配下にあり、CDN 公開（tools/publish_cdn.py）でも配信されます。CDN・静的ホスト上では /api が存在しないため「サーバーに保存」「設定を削除」は自動的に無効化されますが、「ブラウザに保存」・JSON 生成・ダウンロードはそのまま使えます

5. 動作の詳細・注意点

  • エンジンごとのファイル: web/cesium/ui.config.json と web/maplibre/ui.config.json は別物です。各エンジンの index.html 基準で読み込まれます
  • 適用タイミング: 起動時のプロジェクト読込前に1回適用します。あくまで初期状態の設定で、読込後の変更はページ再読み込みで反映されます
  • ブラウザ保存の優先: localStorage（管理画面の「ブラウザに保存」）に設定があるブラウザでは、ui.config.json ファイルよりそちらが優先されます。ファイルを更新してもブラウザ保存が残っていると反映されないため、配布物側の変更を確認する際は「ブラウザ保存を削除」で解除してください
  • 非表示の確実性: hide で隠した要素は display:none（important 指定）で隠すため、パネル側の CSS（flex 表示等）に関わらず確実に非表示になります
  • AI 制御との関係: 非表示にした UI は汎用ブリッジ（listUiControls）の列挙対象からも外れます
  • アプリの自動更新との関係: 更新時は web/ 全体が差し替えられますが、ui.config.json は旧 web から新 web へ自動で引き継がれるため再配置は不要です
