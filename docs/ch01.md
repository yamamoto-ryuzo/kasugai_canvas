## 1. 全体の判断基準と2D/3D混在構成

- **ローカルPC完結・サーバーレス**で動作させたい
- **2D/3D混在**、**大量データ**をブラウザ上でスムーズに操作したい
- **ドレープ（2Dを3D地形に貼り付け）**、**クリッピング**、**断面表示**などの現場機能が必要
- 日本国内の **PLATEAU / 地理院タイル** との親和性を重視
- 上記を踏まえて、最も推奨される構成は **deck.gl + loaders.gl + Three.js（必要時）**

### 2D/3D 混在の構成

| 混在パターン | 推奨構成 |
|--------------|----------|
| 3D空間に2D図面・画像・UIを配置 | **Three.js / R3F**（CanvasTexture、SVGLoader、Html コンポーネント） |
| 2D地図・GIS上に3Dモデルを重ねる | **CesiumJS** または **Mapbox GL JS + deck.gl** |
| 2Dグラフィックが主軸で一部3D | **PixiJS + Three.js** または **Babylon.js** |
