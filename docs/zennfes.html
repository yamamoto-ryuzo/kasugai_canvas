参加特典

  • さくらのAI Engine：無償プランで Chat completions（テキスト応答生成）を月 3,000 リクエストまで無料（Audio transcriptions・Audio speeches は月 50 リクエスト）
  • さくらのVPS：クレジットカード払い選択時、全プランで 2 週間の無料お試し期間
  • さくらのレンタルサーバ：スタンダードプランを利用開始から 92 日間無償で使えるクーポン（要申請・数に限りあり）

KASUGAI Canvas との関連

  • さくらのAI Engine：OpenAI・Anthropic 互換 API を提供するため、内蔵AI の OpenAI互換プロバイダ として設定できます（【API】内蔵AI 参照）。設定画面には専用プロバイダ「【API】さくらAIEngine」（エンドポイント https://api.ai.sakura.ad.jp/v1 固定）を用意済みで、プロバイダ選択 → アカウントトークン入力 → 「モデル一覧を取得」で接続確認まで UI 上で完結します。Gemini 以外のモデルで GIS ツールの function calling を試す経路として使えます。
  • さくらのVPS / レンタルサーバ：.kasc+DATA/ のデータホストや、ローカルアプリの常時稼働先として活用できます（ブラウザ WebGIS ガイド の外部ホスト配信に相当）。

検証方針（徹底検証賞）

検証テーマ：「国内 OpenAI 互換 API で GIS エージェントは実用になるか」 — さくらのAI Engine を内蔵AI のプロバイダとして接続し、62ツールの function calling ループがどこまで回るかを系統的に検証します。検証に必要な機能は積極的に新規追加する方針で、実際に専用プロバイダ「【API】さくらAIEngine」（エンドポイント固定・トークンとモデルのみ入力）と「モデル一覧を取得」ボタンを実装済みです。

最終ゴール（成果デモ）：「東京の観光地を数か所巡るフライを再生し、AI が各所の見どころを音声でガイドする」動画 — フライ定義・案内文生成・さくら TTS（音声読み上げ・月50回無償枠）での音声合成を1本のデモに収めます。再現手順は「観光地巡り SKILL」（AI への指示書）として整備し、検証記事の目玉デモ兼、機能拡張の実績とします。

検証軸

  • ツール選択精度：日本語の自然な指示から適切なツールが選ばれるか（カメラ・レイヤ・検索等のカテゴリ別）
  • 引数適合率：JSON スキーマに適合する引数が生成されるか
  • 多段ループ完走率：ツール結果を見る往復を複数回こなしてタスク完了に至るか
  • 実シナリオ：「サンプルレイヤ生成 → FlyTo → 資料作成（showReport＋パーマリンク）」の通しデモが成立するか
  • ベースライン比較：同一プロンプト集を Gemini（実績のある既定プロバイダ）にも適用し、相対性能として記録

検証設計

  • 対象モデル：最新のパブリックプレビューモデル Kimi-K2.7-Code（2026/07/28〜）を主対象とし、/models で正確なモデル ID を確認。tools 非対応・精度不足なら gpt-oss-120b 等の通常モデルへフォールバック
  • 評価プロンプト：単発（ツール1回）・多段（複数往復）・シナリオ（資料作成まで）の3段構成。カテゴリ別に代表プロンプトを用意
  • 記録方法：プロンプト・期待ツール・実ツール・引数適否・完走可否・消費リクエスト数を表形式で集計し、再現可能な形で公開（検証手順とプロンプト集も記事に付記）

前提確認とリスク

  • さくらのAI Engine の chat/completions 互換エンドポイントが tools（function calling）パラメータを受け付けるかを最初に確認。非対応・精度不足の場合は「チャレンジ賞」（過程重視の記事）へピボット
  • Canvas はブラウザから API を直接叩くためエンドポイント側の CORS 許可が必要。非対応ならローカルアプリの中継経由に切替（これ自体も記事の題材）
  • リクエスト予算は無償枠 月3,000。1ツール往復=1リクエストとしてモデル×プロンプトのマトリクスを予算内に設計（多段ループは消費が膨らむため試行回数を制御）
