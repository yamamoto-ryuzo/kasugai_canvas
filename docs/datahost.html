KASUGAI Canvas v6.2.0

外部データホスト（.kasc + DATA/ の静的配信）

全体構成 — エンジンとデータは分離

KASUGAI Canvas は エンジン（プレイヤー本体）とデータ（.kasc + DATA/）が分離した設計です。 エンジンは CDN（kasugai-canvas-web）が配信し、 データは任意の静的ホストに置くだけで、?kasc=<URL> で再生できます（サーバーレス・インストール不要）。 CDN はエンジン本体のみを配信し、プロジェクトのカタログは持ちません — 変動するプロジェクト一覧は各データホスト側が持つ設計です。

配置するファイル — 必須3点セット

再生に必要な最低限は .kasc ファイル1つ、一覧・選択肢に出すには projects.json と <id>/ フォルダを加えた3点が必須です。

（データホスト）/
  • projects.json必須群マニフェスト。一覧・選択肢に使用。未登録時は単独プロジェクトとして <id> 等を名に使う
  • <id>/必須フォルダ名 = プロジェクトID。?kasc= URL は <id>/kasugai_canvas.kasc を前提
    • kasugai_canvas.kasc必須CDN エンジンの ?kasc= に指定する URL（これだけで動く）。書式は .kasc 設定仕様
    • project.json任意プロジェクト名の表示に使用
    • DATA/条件付き相対参照データがある場合のみ
ファイル必須条件
<id>/kasugai_canvas.kasc 必須 ?kasc= に渡す URL は この .kasc ファイルの URL そのもの。DATA/ 等の相対参照はこの URL のフォルダ基準で解決されます。全レイヤーが URL 直参照ならこれだけで動きます。書式の詳細は .kasc 設定仕様 を参照
<id>/DATA/ 条件付き .kasc 内で DATA/... 等の相対参照しているローカルデータがある場合のみ（.kasc と同じフォルダに置く）
<id>/project.json 任意 単独プロジェクトの表示名として優先（一覧・複数選択では projects.json の title が優先）。無ければ <id>・ファイル名が使われる
projects.json への登録 必須（一覧・選択肢に出すため） 群マニフェスト。?kasc= で開いたエンジンが .kasc の祖先として読み、同一ホスト上の他プロジェクトをドロップボックスに並べます。未登録・無タイトルの単独プロジェクトは <id>（フォルダ名）をプロジェクト名として扱います

追加手順（ファイル順に設定）

  1. projects.json【必須】 — ホスト直下の群マニフェストに、プロジェクトを1エントリ追記します。 
    [\n  { "id": "default", "title": "サンプルプロジェクト" },\n  { "id": "<id>", "title": "<プロジェクト名>" }\n]
    未登録でも単独プロジェクトとしては動きますが（<id> 等が名に使われる）、一覧・選択肢に出すには登録が必須です。
  2. <id>/【必須】 — フォルダ名 = プロジェクトID で作ります。?kasc= の URL は …/<id>/kasugai_canvas.kasc になる前提です。
  3. <id>/kasugai_canvas.kasc【必須】 — QGIS プラグイン geo_webview の Export 出力をそのまま置きます。このファイルの URL を CDN エンジンの ?kasc= に指定するのが再生の本体で、これだけ置けば動きます。
  4. <id>/project.json（任意） — 表示名を付けたい場合に {"title": "<プロジェクト名>"} と書きます。単独プロジェクトではこの名前が優先され、複数・一覧では projects.json の title が優先されます（無ければ <id>・ファイル名で表示）。
  5. <id>/DATA/（条件付き） — .kasc が DATA/... 等の相対参照を持つローカルデータがある場合のみ、.kasc と同じフォルダに置きます。
  6. 公開 — 静的ホストへアップロードするだけです（GitHub Pages 等）。

再生 URL の形式

https://yamamoto-ryuzo.github.io/kasugai-canvas-web/<stage>/<engine>/?kasc=<ホスト上の .kasc URL>
要素値意味
<stage> stable（既定）/ unstable / latest CDN の配信チャンネル。stable=安定版・unstable=開発版・latest=stable へのリダイレクト
<engine> cesium / maplibre / openlayers / leaflet / gsimaps 再生に使う描画エンジン。cesium がメイン（3D・フル機能）、他は同じ .kasc を読む互換プレイヤー
?kasc= .kasc ファイルの URL（要 URL エンコード） ホスト上のプロジェクトを指定。相対参照は .kasc のある URL 基準で解決

注意点

  • .kasc と DATA/ は同じフォルダに置く — 相対参照は .kasc のある URL を基準に解決されます。
  • CORS — エンジンは別オリジンからデータを fetch するため、ホスト側は Access-Control-Allow-Origin が必要です（GitHub Pages は * が既定でそのまま使えます）。
  • スナップショット方式 — .kasc はエクスポート時点の状態です。QGIS 側の編集は再エクスポートで反映してください。
  • 大きなファイル — GitHub Pages の1ファイル上限は 100MB です。大容量データはオブジェクトストレージ等を URL 直参照で使い分けてください。
