KASUGAI Canvas v1.3.0

ローカルPC・ブラウザ完結で動作する 2D/3D データ可視化システムの技術選定

📋 概要

KASUGAI Canvas は、CesiumJS + Three.js を核とした 2D/3D データ可視化システムです。2D 図面、3D モデル、点群、3DGS、地形タイル、XYZ タイルを同一の 3D 地球空間に重ねて描画できます。

本サイトでは、KASUGAI Canvas の技術選定に関する文書を公開しています。各章は左の目次から、または下のカードから開けます。

🔗 インストール

配布 ZIP / インストーラー

  1. GitHub Releases から kasugai_canvas.zip または kasugai_canvas_setup.zip をダウンロード
  2. ZIP は任意のフォルダに展開、インストーラーはウィザードに従って C:\kasugai\kasugai_canvas へインストール
  3. 同梱の kasugai_canvas.exe を実行するか、ショートカットから起動
  4. 既定でブラウザが開き、KASUGAI Canvas が起動します

📖 使い方

開発起動

cargo run --manifest-path server\Cargo.toml

ブラウザで http://127.0.0.1:8510 を開いてください。インスペクター設定は projects/<project>/kasugai_canvas.config に保存されます。

リリースビルド

python run.py -B

配布用 ZIP と、NSIS が利用可能な場合はインストーラーを download\ に作成します。

🛠️ 実装システム

KASUGAI Canvas は Rust/Axum バックエンドと CesiumJS + Three.js フロントエンドで構成されています。バージョン v1.3.0（正本は server\Cargo.toml）。以下は主要な実装コンポーネントです。

⚙️ Rust / Axum

ローカルPC上で 127.0.0.1:8510 で動作。静的アセット、タイルプロキシ、設定 API を提供

🌍 CesiumJS + Three.js

地球・3D Tiles・DEM ドレープを CesiumJS で、点群・3DGS・GLB 等を Three.js で補完

📊 UI パネル

Layers、Basemap、Camera、Search、Share、Info、Attr、設定 パネルで直感的に操作

🎥 Fly モード

GeoJSON ルートの自動追従と手動操縦、速度・高さ・ピッチ調整

🔗 URL パーマリンク

カメラ情報を URL ハッシュ、プロジェクトなどをクエリに保存。共有 URL コピー対応

📝 インスペクター設定

1 行 種類: 値 形式の kasugai_canvas.config でレイヤー・カメラを一括指定

⛰️ ドレープ・地形

DEM、3D Tiles 表面への XYZ・GeoJSON ドレープ。高さ基準に応じた TerrainProvider 選択

⚠️ 制限・未対応

Three.js 点群 / 3DGS / GLB 表示は現在未対応。将来的な補完対象
