KASUGAI Canvas 技術選定

ローカルPC・ブラウザ完結で動作する 2D/3D データ可視化システムの技術選定ドキュメント

概要

KASUGAI Canvas（CesiumJS + Three.js）は、ローカルPC・ブラウザ完結で動作する 2D/3D データ可視化システムです。同じ 3D 地球空間で 2D 図面、3D モデル、点群、3DGS、地形タイル、XYZ タイルを重ねて描画します。

KASUGAI Canvas の核

  • 描画エンジン：CesiumJS + Three.js
    • CesiumJS：3D 地球・3D Tiles・DEM ドレープ・XYZ 重ね合わせを同一 Scene で一括描画
    • Three.js：点群、3DGS、GLB 等の高度な 3D 表現を補完
  • ロード・変換：loaders.gl + Web Worker
  • 目的：同じ 3D 地球空間で 2D 図面、3D モデル、点群、3DGS、地形タイル、XYZ タイルを重ねて描画
