KASUGAI Canvas v7.2.0

QGIS・GDAL連携 — geo_webview によるエクスポート連携：実装済みの再現範囲と未対応課題

本ページは geo_webview による QGIS→Canvas エクスポートの実装済みの再現範囲をまとめる。 連携の基本方針・将来構想は QGIS連携 — 連携アーキテクチャ、 描画性能とデータ形式の既定は 描画性能とデータ形式の整備方針 を参照。

QGIS連携：実装済みの再現範囲

QGIS プラグイン geo_webview の kasugaiExport （パネル「KASUGAI」ボタン / GET :8089/kasugai / bridge kasugaiExport / Canvas 側「QGISから取り込み」ボタン）は、 プロジェクトのレイヤーツリーを走査して .kasc + canvas_data/ を出力し、 起動中の Canvas へ登録・切替（または静的ホスト経由で ?kasc= 再生）する。以下は現在「そのまま」再現される項目。

レイヤー → .kasc 行の対応

QGIS レイヤー 出力 備考
ベクター（GPKG/GeoJSON/Parquet/FGB ソース） gpkg: / geojson: / geoparquet: / flatgeobuf: のネイティブ参照 変換せずそのまま。ローカルは canvas_data/ へ複製、URL は直参照。 GPKG は table= 対応
ベクター（上記以外のソース・再投影必要） geojson: EPSG:4326 の GeoJSON へ変換して canvas_data/ へ出力
CSV/TSV（delimitedtext / ogr） duckdb: lon=/lat=/geom= 付き
プロバイダフィルタ（subsetString） where=（gpkg/duckdb）・ duckdb:+format=parquet（parquet）・GeoJSON 変換 フィルタに | を含む場合は GeoJSON 変換で反映
3D Tiles（QgsTiledSceneLayer） 3dtiles: ローカル tileset は canvas_data/ へ複製（サイズ上限あり）
XYZ タイル xyz: / base: 最下段の表示中 XYZ または「背景図」「ベースマップ」グループ内は base: 行。minZoom=/maxZoom= 反映。 ローカルタイルツリーは canvas_data/ へ複製

属性テーブル（ジオメトリなし）・メッシュ・ベクタータイル・点群・注記・プラグインレイヤ スキップ エクスポート結果の skipped に理由付きで記録 （#50）

スタイル（.qml）の再現

QGIS 側の設定 Canvas 側
ベクターの現在スタイル canvas_data/<slug>.qml として保存し style=canvas_data/<slug>.qml で参照。<renderer-v2> の単一・分類（categorizedSymbol）・段階（graduatedSymbol）・ルール（RuleBased・ 式サブセット評価）レンダラをコンパイルして適用。シンボルレイヤ （マーカー/SVG・フォント/ラスタ・ライン実線破線＋結合部/端部/オフセット・ 塗りつぶし・ハッチ/ドット/画像パターン）・データ定義プロパティ・ シンボルレイヤのブレンドモード/ペイントエフェクト （blur/dropShadow/glow/innerGlow/colourize/transform の近似）・ heatmapRenderer（OpenLayers/MapLibre/Cesium でネイティブまたは heatmap.js 近似。Leaflet は leaflet.heat で radius/weight_expression/maximum_value/colorramp も反映・ Navara はフォールバック点）・ pointCluster（OL/MapLibre/Cesium/Leaflet のクラスタ。 Leaflet は tolerance→maxClusterRadius・件数バッジ色も反映）・ invertedPolygonRenderer（地物を穴とした世界矩形マスクで再現）・ 25dRenderer（固定高さの押出し近似）・ RandomMarkerFill（count_method=面積密度時は間隔を sqrt(density_area/point_count) 換算し規則配置で近似。 個数直接・seed・clip_points も spec へ保持）・ SVGFill（実名 svgFile 参照・data の hex 埋込 SVG 対応）・ <labeling> ラベル・縮尺依存ルール・ is_layer_visible() に対応。
レイヤー自体の表示制御も再現: ルート <qgis> の labelsEnabled="0" でラベル抑制、 hasScaleBasedVisibilityFlag＋minScale/ maxScale は layerScale（縮尺分母）として spec へ保持（縮尺連動再評価のゲートにも含まれる）。
式評価は QgsExpression のサブセット実装。構文: AND/OR/NOT・比較(= != <> < <= > >=)・ 算術(+ - * / %)・|| 連結・ IN/LIKE/ILIKE/BETWEEN/IS [NOT] NULL・CASE WHEN … END・ "フィールド"/裸属性名/'文字列'・ 式変数 @map_scale（var('map_scale')・裸の map_scale も可。各エンジンが現在縮尺を供給し、縮尺変化で スタイル・データ定義・ラベルを再評価）。対応関数: 条件=if nullif coalesce try／ 変数=var is_layer_visible／ 数値=abs ceil(ing) floor round exp ln log log2 log10 sqrt sign min max clamp pi rand randf radians degrees sin cos tan asin acos atan atan2 scale_linear scale_exp／ 文字列=lower upper title length(len) substr left right strpos replace trim ltrim rtrim lpad rpad concat format format_number char unicode wordwrap／ 正規表現=regexp_match regexp_substr regexp_replace regexp_escape／ 色=ramp_color color_rgb color_rgba／ 変換=to_int to_real to_string to_text（QGIS2 旧名 toint toreal tostring も可）／ 日時=to_date to_datetime to_time（+旧名）format_date make_date make_datetime make_time year month day hour minute second day_of_week week now／ 配列=array array_get array_length array_first array_last array_contains array_append array_prepend array_cat array_distinct array_reverse array_slice array_sort array_to_string string_to_array／ その他=uuid／ ユーザー関数=zen2han（geo_userfunc 移植。全角英数字→半角。 QGIS 側で @qgsfunction 登録されたもののみ対象）。 未対応: 集計系 （aggregate relation_aggregate array_agg 等）・ attribute() get_feature() overlay_* 等の地物参照系・ 一般のジオメトリ関数（$area intersects buffer 等。 geometryGenerator は $geometry＋常用ジオメトリ関数の 簡易評価のみ）・ラスタ/統計系・^ べき乗
ラベル（<labeling>） テキスト（フィールド/式）・フォント（サイズ/太字/斜体/下線/取り消し線/ 字間・単語間・大文字化・縦書き※DOM 系）・色・透明度・バッファ（ハロー。 bufferNoFill 中空ハローは canvas ラスタライズで再現。 MapLibre は icon-image 化）・ 配置（モード/quadOffset/距離/オフセット/回転/リピート距離/centroidInside・ fitInsidePolygon/ライン追従・曲線は中点回転で近似）・<rendering> （縮尺表示/上限数＋優先度・zIndex/最小地物サイズ/障害物係数/ displayAll→重なり許容/upsidedownLabels/折返し文字・行長/方向記号/ 数値フォーマット）・<dd_properties> ラベル DD （Show/Size/Color/Bold/回転/OffsetXY/PositionX,Y 等）・ラベル背景（矩形/楕円・ 塗り/枠線）・コールアウト（Cesium で引き出し線）。
重なり禁止: MapLibre=text-allow-overlap:false （displayAll/allowDegraded 時は true）、OpenLayers=declutter:true、 Cesium=画面投影ベースの自前 declutter（priority/zIndex 順＋ predefinedPositionOrder 順位付き位置への自動移動。カメラ停止時に再計算）、 Leaflet=DOM 矩形衝突判定で非表示。
ラベル障害物（obstacle）: obstacle="1" かつ係数>0 の地物を他ラベルの障害物として扱う。Cesium=地物の画面投影 ジオメトリで実交差判定（obstacleType の 内部/境界のみ/全体 を 区別）、Leaflet=地物 bbox 近似、MapLibre/OpenLayers=衝突判定の制約上 非適用。
未対応/近似: SimpleLine の線端トリム(trim_distance_start/end)は全エンジンでジオメトリ切断近似（基準縮尺1:1万換算。OpenLayers は解像度連動）・破線開始オフセット(dash_pattern_offset)は OpenLayers/Leaflet のみ・ライン <effect> は MapLibre が line-blur・Cesium が PolylineGlowMaterial で近似・ジオメトリジェネレータ・ダイアグラム(Pie/Histogram)は簡易canvas描画・InterpolatedLineはセグメント分割近似・AnimatedMarkerは先頭フレーム静止表示・ラベルマスクは不透明背景近似・ ドロップシャドウは Cesium/Leaflet でオフセット近似・ MarkerLine/HashLine/ArrowLine の形状は OpenLayers・Cesium （補助エンティティでマーカー/刻み/矢羽を配置）と MapLibre （symbol-placement:line＋icon-image で マーカー/刻みを線上配置。HashLine の刻み向きは QGIS と同じ line角度+hash_angle−90°）で形状再現。 RasterLine は MapLibre の line-pattern で画像を線に沿って 繰り返す（Leaflet/Navara は単色近似）・InterpolatedLine は Cesium で幅/色の 線形補間を再現（ドレープ時は色のみ。MapLibre は line-gradient で色補間。その他は単色近似）・ FilledLine（塗りつぶしライン）= ネストした fill サブシンボルを取り込み、 Cesium は CorridorGraphics で line_width 幅の帯を塗り （outline は帯両縁ラインで近似）、MapLibre/OpenLayers/Leaflet/Navara は 塗り代表色の太線近似・LinearReferencing（里程標）= interval 間隔の 標点へ距離ラベル＋任意マーカー（Cesium=補助エンティティ、 MapLibre=生成点 symbol レイヤ、OpenLayers=ジオメトリ関数スタイル、 Leaflet=permanent tooltip、Navara=生成点 text マテリアル。 地図単位=m・QGIS と同じく基線は非表示）・VectorField（ベクトル場）= x_attribute/y_attribute（Cartesian/Polar/HeightOnly）で矢印画像を 回転・拡縮して全エンジン表示（ネスト SimpleLine の色・太さを反映。 線形描画ではなく画像近似）・MaskMarker=ネストしたマーカー サブシンボルはそのまま描画するが、QGIS のマスク効果（ラベル・他 シンボルの遮蔽抜き）は全エンジン未対応（警告のみ）・ symbollevels="1" をパースし地物の最小 pass を z 順位近似 へ（MapLibre=*-sort-key、OpenLayers=スタイル zIndex、 Cesium=ground プリミティブ zIndex、Leaflet=地物追加順ソート。 QGIS 本来の「全地物をレイヤ pass 順に一括描画」は Web エンジンでは 再現不能のため地物単位の近似）・ ラベル配置候補順（predefinedPositionOrder）は Cesium=declutter の候補位置順・MapLibre=text-variable-anchor ＋text-radial-offset・Navara=variableAnchors に写像（OpenLayers/Leaflet は先頭候補の固定アンカー近似）
シンボルが参照する画像（SVG/ラスタ） canvas_data/ へ複製し .qml 内の参照を書き換え （QGIS 内蔵 SVG や絶対パスも拾う）
GPKG への「スタイルをデータベースに保存」 embed_gpkg_style=True で layer_styles （useAsDefault）へも保存 → Canvas が style= 未指定時に自動適用
QML 凡例 レイヤ一覧に条件別スウォッチ表示＋凡例単位の表示/非表示 （legendHidden → 再描画反映。AI ツール setLayerLegendVisible/listLayers からも操作可）
未対応レンダラ/シンボル要素（2.5Dは固定高さ近似対応・未再現は⚠バッジ表示） 最も近い表現にフォールバックし warnings に記録 （#54、 #55）

エンジン別の QML 再現度: Cesium=完全対応（entity/primitive 両経路・ドレープ・ラベル。 ラベル衝突回避はエンジンに機能がないため画面投影ベースの自前 declutter で再現）、 MapLibre=スタイルレイヤ化＋ラベルベイク＋衝突回避 （text-allow-overlap/keep-upright/sort-key/spacing/配置モード別 symbol レイヤ）、 OpenLayers=styleFunction＋declutter 衝突回避＋ライン配置/ ラベル背景/縮尺・最小地物サイズゲート、 Leaflet=Path options＋tooltip ラベル（DOM 装飾: 下線・ 字間・行間・背景・縦書き・回転・縮尺連動）、 Navara=FeatureEvaluator で地物ごとにスタイルを評価 （塗り/線色・線幅・透過度・extrudedHeight）。マーカーは canvas 画像を billboard マテリアルの地物別 image（dataURL→テクスチャアトラス）で描画し、 invertedPolygonRenderer は世界矩形−地物穴マスク、25d/押出しは extrudedHeight で再現。<labeling> は text マテリアル＋FeatureEvaluator で地物ごとラベル 文字列・サイズ・declutter 優先度を評価（フォントは Google Fonts CSS から unicode-range 分割で登録し、取得失敗時はラベル非表示）。 縮尺連動も対応: @map_scale DD・ルール別縮尺 （scalemin/maxdenom）・ラベル縮尺表示（scaleVisibility）は カメラ高→縮尺分母（ルール縮尺→距離換算と同係数）で評価し、 カメラ停止（moveend）後に対象レイヤを再マウントして現在縮尺で 再評価する（範囲外ラベルは text メッシュのみ show=false）。 GSI Maps=未対応（凡例スウォッチのみ）。

MapLibre のベクター拡張: extrude=<m>/z=<m> オプションと QML 2.5D レンダラは fill-extrusion レイヤへ変換、 InterpolatedLine は lineMetrics＋line-gradient で始点→終点色をネイティブ補間（幅は始終点の大きい方で近似）。

Cesium のベクター/3D Tiles 拡張（CesiumJS 監査 2026-11 追加、entity 経路）: scaledist/transldist/pixoffdist（距離連動の スケール・透過・ピクセルオフセット）、splitdir（クリッピング面の 左右振分）、strot（面テクスチャ回転）、subregion （billboard スプライト切出し）。3dtiles: 行は tilestyle/tilecolor/tileshow/ tilepointsize/sse/edl で Cesium3DTileStyle と点群描画を制御。URL スロットの予約値 osm は Cesium ion の OSM Buildings を読み込み、 ionkey= でアクセストークンを指定できる。scene3d: 行は fxaa/bloom/ao/tonemap/ blur/brightness/depthview/ silhouette（クリック地物の縁取り）/ material（globe.material 地表ファブリック）/ matuniforms（ファブリック uniforms を JSON で上書き）/ groundatmosphere/specmap（URL または off=既定環境マップ復帰）/shcoeffs（拡散 IBL 球面調和係数 JSON）/ minzoom/maxzoom/tilt/ sscc（ScreenSpaceCameraController の残り全フラグを JSON 一括指定） （カメラ制約）を追加受理し、QGIS 3D シーン設定を超える Cesium 固有の後処理・大気・環境マップ・カメラ制御を 同一行で指定できる。terrain: 行の url= は 任意の CesiumTerrainProvider エンドポイントを直接指定でき、 model: 行の modelopts= は ModelGraphics の 残り全引数（色・シルエット・IBL・ノード変換・アーティキュレーション・ カスタムシェーダ等）を JSON で一括指定する。wms: レイヤーはクリック時に GetFeatureInfo を自動発行して属性パネルへ追記する （infoformat= で応答形式指定）。

連携の起動経路

経路 動作
パネル「KASUGAI」/ GET :8089/kasugai / bridge kasugaiExport / Canvas「QGISから取り込み」 エクスポート → 起動中 Canvas（127.0.0.1:8510）へ /api/projects/register 登録 → switchProject 切替
route=local|qgis-http（フォールバック） Canvas 未起動時は geo_webview 内蔵 HTTP がエンジン HTML と /export-data/ でデータを配信してブラウザ起動
route=hosted CDN ホスト版エンジン（kasugai-canvas-web）＋ /export-data/ でサーバレス再生
emit_launchers / emit_zip エンジン起動 HTML を同梱 / 一式を kasugai_canvas_*.zip 化（Re:Earth geo_suite の qgis: 行が直接取り込み可・/export-data/ でも取得可）
AI チャットの QGIS Live 接続（起動時に自動検出・接続。 管理 → AI → データソースの「起動中の QGIS に接続」は手動再接続用） /api/qgis-live/discover が稼働中の QGIS Live Driver セッションを ~/.qgis-live/ レジストリから検出し、 /api/qgis-live/mcp リレー経由で QGIS の /mcp （Streamable HTTP・トークンはリレーが付与）を AI チャットの MCP サーバーとして登録。ローカルアプリ不在の CDN ホスト版では geo_webview の :8089/live/mcp-discover をプローブし /live/mcp リレー（loopback 限定）へ自動フォールバック。qgis_describe_plugins で各プラグインの 機能を自己発見し qgis_bridge_call で kasugaiExport 等を実行できる（AI オーケストレーション。 qgis_pyeval/qgis_eval/reload 系は 「書き込み系ツールも AI に公開する」ゲート対象）
