QGIS・GDAL連携 — geo_webview によるエクスポート連携：実装済みの再現範囲と未対応課題

本ページは geo_webview による QGIS→Canvas エクスポートの実装済みの再現範囲をまとめる。 連携の基本方針・将来構想は QGIS・GDAL連携 — 方針・構想、 描画性能とデータ形式の既定は 描画性能とデータ形式の整備方針 を参照。

QGIS連携：実装済みの再現範囲

QGIS プラグイン geo_webview の kasugaiExport （パネル「KASUGAI」ボタン / GET :8089/kasugai / bridge kasugaiExport / Canvas 側「QGISから取り込み」ボタン）は、 プロジェクトのレイヤーツリーを走査して .kasc + DATA/ を出力し、 起動中の Canvas へ登録・切替（または静的ホスト経由で ?kasc= 再生）する。以下は現在「そのまま」再現される項目。

レイヤー → .kasc 行の対応

QGIS レイヤー 出力 備考
ベクター（GPKG/GeoJSON/Parquet/FGB ソース） gpkg: / geojson: / geoparquet: / flatgeobuf: のネイティブ参照 変換せずそのまま。ローカルは DATA/ へ複製、URL は直参照。 GPKG は table= 対応
ベクター（上記以外のソース・再投影必要） geojson: EPSG:4326 の GeoJSON へ変換して DATA/ へ出力
CSV/TSV（delimitedtext / ogr） duckdb: lon=/lat=/geom= 付き
プロバイダフィルタ（subsetString） where=（gpkg/duckdb）・ duckdb:+format=parquet（parquet）・GeoJSON 変換 フィルタに | を含む場合は GeoJSON 変換で反映
3D Tiles（QgsTiledSceneLayer） 3dtiles: ローカル tileset は DATA/ へ複製（サイズ上限あり）
XYZ タイル xyz: / base: 最下段の表示中 XYZ または「背景図」「ベースマップ」グループ内は base: 行。minZoom=/maxZoom= 反映。 ローカルタイルツリーは DATA/ へ複製
WMS wms: layers=/styles=/format= を引継ぎ。 WMTS は未対応（#51）
GeoTIFF/COG（GDAL ラスタ） geotiff: ローカル .tif 系は DATA/ へ複製、URL/vsicurl は直参照。 それ以外のラスタ形式はスキップ（#53）。 ラスタレンダラは Canvas 側オプションで再現可（colormap=疑似カラー/ hillshade=陰影/stretch=minmax・min=/max=値域/ nodata=透過値。geo_webview 側のオプション出力は残課題 #52）
属性テーブル（ジオメトリなし）・メッシュ・ベクタータイル・点群・注記・プラグインレイヤ スキップ エクスポート結果の skipped に理由付きで記録 （#50）

表示設定の引継ぎ

QGIS 側の設定 Canvas 側
レイヤー表示チェック | off。hidden_as_off=True またはテーマ出力時は非表示レイヤーも | off 付きで出力
グループ階層 タイトルを group/layer パンくず形式に。排他グループは group//layer（Canvas 側で排他切替）
レイヤー不透明度 opacity=（XYZ/WMS/GeoTIFF/ベクター。QML・既定両経路で アルファ乗算。geo_webview 側のベクター出力は残課題 #58）
縮尺表示（minimumScale/maximumScale） minScale=/maxScale=（引き側/寄り側限界。 QML ルールの縮尺範囲と積集合で併存）
出典・利用条件（layer attribution） attr=
現在のキャンバス範囲 cam: 行（中心座標＋高さ換算）
ブックマーク（プロジェクト＋アプリケーション） bookmarks.xml（qgis_bookmarks 形式・EPSG:4326 正規化）＋ bookmark: 行 → カメラプリセット
マップテーマ theme: 行 → 表示状態プリセット（テーマの可視レイヤ名を タイトル一致で記述）。テーマ記録の名前付きスタイルは DATA/<slug>__<theme>.qml として出力し ;style= で付与（テーマ別スタイル切替を再現・v4.6.0〜）
アトラス有効な印刷レイアウト fly_geojson: 行＋DATA/atlas_*.geojson → Fly パネルのプレゼン巡回ルート。各ページ表示範囲を巡回し、 座標 Z にページを収めるカメラ高を焼き込む（点ごとの可変縮尺に対応・ geo_webview v4.8.0〜）。印刷レイアウト本体の PDF 出力は 印刷ダイアログの「QGIS レイアウトPDF」から（/layouts・ /layout-pdf、アトラスは全ページ出力）
破損レイヤー（ソース未達） readLayerXml で再生成してエクスポートを試行

スタイル（.qml）の再現

QGIS 側の設定 Canvas 側
ベクターの現在スタイル DATA/<slug>.qml として保存し style=DATA/<slug>.qml で参照。<renderer-v2> の単一・分類（categorizedSymbol）・段階（graduatedSymbol）・ルール（RuleBased・ 式サブセット評価）レンダラをコンパイルして適用。シンボルレイヤ （マーカー/SVG・フォント/ラスタ・ライン実線破線＋結合部/端部/オフセット・ 塗りつぶし・ハッチ/ドット/画像パターン）・データ定義プロパティ・ シンボルレイヤのブレンドモード/ペイントエフェクト （blur/dropShadow/glow/innerGlow/colourize/transform の近似）・ heatmapRenderer（OpenLayers/MapLibre/Cesium でネイティブまたは heatmap.js 近似）・pointCluster（OL/MapLibre/Cesium のクラスタ）・ <labeling> ラベル・縮尺依存ルール・ is_layer_visible() に対応
ラベル（<labeling>） テキスト（フィールド/式）・フォント（サイズ/太字/斜体/下線/取り消し線/ 字間・単語間・大文字化・縦書き※DOM 系）・色・透明度・バッファ（ハロー）・ 配置（モード/quadOffset/距離/オフセット/回転/リピート距離/centroidInside・ fitInsidePolygon/ライン追従・曲線は中点回転で近似）・<rendering> （縮尺表示/上限数＋優先度・zIndex/最小地物サイズ/障害物係数/ displayAll→重なり許容/upsidedownLabels/折返し文字・行長/方向記号/ 数値フォーマット）・<dd_properties> ラベル DD （Show/Size/Color/Bold/回転/OffsetXY/PositionX,Y 等）・ラベル背景（矩形/楕円・ 塗り/枠線）・コールアウト（Cesium で引き出し線）。
重なり禁止: MapLibre=text-allow-overlap:false （displayAll/allowDegraded 時は true）、OpenLayers=declutter:true、 Cesium=画面投影ベースの自前 declutter（priority/zIndex 順＋ predefinedPositionOrder 順位付き位置への自動移動。カメラ停止時に再計算）、 Leaflet=DOM 矩形衝突判定で非表示。
未対応/近似: ジオメトリジェネレータ・ラベルマスクは不透明背景近似・ ドロップシャドウは Cesium/Leaflet でオフセット近似・ MarkerLine/HashLine/ArrowLine の形状は OpenLayers のみ形状再現 （他エンジンは単色近似）・シンボルレベルの地物横断描画順は近似
シンボルが参照する画像（SVG/ラスタ） DATA/ へ複製し .qml 内の参照を書き換え （QGIS 内蔵 SVG や絶対パスも拾う）
GPKG への「スタイルをデータベースに保存」 embed_gpkg_style=True で layer_styles （useAsDefault）へも保存 → Canvas が style= 未指定時に自動適用
QML 凡例 レイヤ一覧に条件別スウォッチ表示＋凡例単位の表示/非表示 （legendHidden → 再描画反映。AI ツール setLayerLegendVisible/listLayers からも操作可）
未対応レンダラ/シンボル要素（2.5Dは固定高さ近似対応・未再現は⚠バッジ表示） 最も近い表現にフォールバックし warnings に記録 （#54、 #55）

エンジン別の QML 再現度: Cesium=完全対応（entity/primitive 両経路・ドレープ・ラベル。 ラベル衝突回避はエンジンに機能がなく未再現）、 MapLibre=スタイルレイヤ化＋ラベルベイク＋衝突回避 （text-allow-overlap/keep-upright/sort-key/spacing/配置モード別 symbol レイヤ）、 OpenLayers=styleFunction＋declutter 衝突回避＋ライン配置/ ラベル背景/縮尺・最小地物サイズゲート、 Leaflet=Path options＋tooltip ラベル（DOM 装飾: 下線・ 字間・行間・背景・縦書き・回転・縮尺連動）、 Navara=代表地物のスタイルをレイヤー単位マテリアルへ、 GSI Maps=未対応（凡例スウォッチのみ）。

連携の起動経路

経路 動作
パネル「KASUGAI」/ GET :8089/kasugai / bridge kasugaiExport / Canvas「QGISから取り込み」 エクスポート → 起動中 Canvas（127.0.0.1:8510）へ /api/projects/register 登録 → switchProject 切替
route=local|qgis-http（フォールバック） Canvas 未起動時は geo_webview 内蔵 HTTP がエンジン HTML と /export-data/ でデータを配信してブラウザ起動
route=hosted CDN ホスト版エンジン（kasugai-canvas-web）＋ /export-data/ でサーバレス再生
emit_launchers / emit_zip エンジン起動 HTML を同梱 / 一式を kasugai_canvas_*.zip 化（Re:Earth geo_suite の qgis: 行が直接取り込み可・/export-data/ でも取得可）
AI チャット「起動中の QGIS に接続」（管理 → AI → データソース） /api/qgis-live/discover が稼働中の QGIS Live Driver セッションを ~/.qgis-live/ レジストリから検出し、 /api/qgis-live/mcp リレー経由で QGIS の /mcp （Streamable HTTP・トークンはリレーが付与）を AI チャットの MCP サーバーとして登録。ローカルアプリ不在の CDN ホスト版では geo_webview の :8089/live/mcp-discover をプローブし /live/mcp リレー（loopback 限定）へ自動フォールバック。qgis_describe_plugins で各プラグインの 機能を自己発見し qgis_bridge_call で kasugaiExport 等を実行できる（AI オーケストレーション。 qgis_pyeval/qgis_eval/reload 系は 「書き込み系ツールも AI に公開する」ゲート対象）
