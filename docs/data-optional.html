オプションデータ形式（エンジン別対応）

標準形式の判定は 主要4エンジン（Cesium・MapLibre・OpenLayers・Leaflet） で行います。このページの形式はその4エンジンの一部でしか描画できないもので、未対応エンジンではレイヤ行は一覧に残りますがグレーアウトされ描画されません（情報タブに警告が出ます）。複数エンジンで使い回すプロジェクトでは データ形式（標準） の形式を選んでください。

形式カード

ネイティブ対応（対応エンジン限定）

🧩 MVT / PMTiles ネイティブ: MapLibre

mvt:/pmtiles: で指定するベクトルタイル。ネイティブは MapLibre（両形式・pmtiles:// プロトコル・全速）と OpenLayers（layer/VectorTile+source/VectorTile+format/MVT。pmtiles は pmtiles.js の Range 読み出しを tileLoadFunction で接続・属性クリックも有効）で、試験エンジンの Navara も mvt: のみネイティブ対応。Leaflet は leaflet.vectorgrid（CDN 遅延ロード）で実ベクトル描画し、地物クリックの属性表示・renderer=canvas 切替・tms=/subdomains=/bbox= にも対応（pmtiles は pmtiles.js の Range 読み出しをタイル取得へ接続）。Cesium は変換・低速経路（タイルをデコード→canvas ラスタライズして imagery として重ねる）のため、表示は可能だがオーバーズームのシャープさ・属性取得・ベクター検索の利点は失われる。layers= でソースレイヤ指定

🗿 GLB / glTF モデル ネイティブ: Cesium のみ

model: で単体の 3D モデルを配置。スケール・最小ピクセルサイズ・modelopts=（マテリアル・ノード変換等）を指定可能。対応は Cesium のみ

⛰️ 地形（terrain:） ネイティブ: Cesium 中心

terrain: 行で地形を制御（url= 任意地形ソース・exaggeration= 垂直誇張・shading= 陰影・generator=flat フラット地形）。Cesium が全オプションに対応。MapLibre も exaggeration=（raster-dem テレイン）・url=+`encoding=`（TileJSON または {z}/{x}/{y} テンプレートの任意 DEM）・shading=on|relief|both（DEM 共有の hillshade/color-relief レイヤ。3D地形OFFでも陰影・段彩だけ表示可）・generator=flat を反映し、表示設定に陰影・段彩トグルとメルカトル/地球儀（globe）投影切替がある。light: 行（az=/el=/intensity=/color=）は setLight へ反映。Navara は誇張・陰影・フラットを反映。2D エンジン（OpenLayers/Leaflet/GSI Maps）では無効

変換・代替経路（低速寄り）

🌈 GeoTIFF / COG 対応: Cesium・OpenLayers

geotiff: / cog: / tiff:（または .tif/.tiff ファイルの直接読み込み）でブラウザ内デコードしてラスタ表示。ドローン測量等の GeoTIFF/COG オルソ画像はこの経路（タイル化済みオルソは標準の xyz:、単一画像は image: を推奨）。Cesium は geotiff.js 遅延ロードの独自経路でタイルモードと地物ドレープモードに対応。OpenLayers は layer/WebGLTile+source/GeoTIFF のネイティブ経路（ライブラリ内蔵 geotiff.js が COG の Range 読み出し・オーバービュー・任意座標系のリプロジェクトを処理。bands=/nodata=/opacity= 対応）。MapLibre・Leaflet は未対応

📦 FlatGeobuf（flatgeobuf:/fgb:） GeoJSON 正規化・全エンジン

空間インデックス+HTTP Range で表示範囲の地物だけ読むクエリ系（bbox=auto 既定 ON・カメラ移動で再クエリ。bbox=off で全件読み込み系）。索引なし・Range 非対応サーバーは全件へ自動フォールバック。seekable Zstandard 圧縮（.fgb.zst/.fgbz）も範囲読みのまま対応。proxy=on（ローカルサーバーの /api/fetch 経由・Range 転送で CORS 回避）・nocache=on（Range バッファ無効化・更新されるリモート FGB 向け）・key=（Bearer 認証）・where=（クライアント評価）に対応。レイヤー一覧の FGB バッジ（Cesium）でヘッダメタ（件数・索引有無・CRS・列定義）を表示し、listLayers API の fgb フィールドからも参照できる（未ロード行はヘッダのみ Range 取得して先に表示）。エクスポート（レイヤー → .fgb）も可能で、出力には地物を Hilbert ソートした packed R-tree の空間インデックスを自前で付与する（ライブラリの serialize が索引を書けないため spec 準拠で実装）。書き出した FGB はそのまま flatgeobuf: + bbox=auto の範囲読みに対応する

KASUGAI Canvas への読み込み方

データ 描画エンジン ロード方法
GLB / 3D Tiles CesiumJS (Model / Cesium3DTileset) または Three.js (GLTFLoader / 3DTilesRenderer) 3dtiles: 行で URL 指定。LOD・ストリーミングは CesiumJS が管理
点群 (PLY / LAS) CesiumJS (Cesium3DTileset pnts) または Three.js (Points / Potree) PLY/LAZ → 3D Tiles 変換 → 3dtiles: で読み込み
3DGS (PLY / SPZ) Three.js 専用レンダラー gaussian-splats-3d / SuperSplat 等で読み込み

点群の扱い

  • LAS/LAZ：測量・LiDAR での標準。LAZ は圧縮形式
  • PLY：簡易入出力用。点位置 + RGB のみの軽量点群も可能
  • EPT (Entwine Point Tile) / Potree 形式：ブラウザ向け大規模点群配信。八分木階層で LOD 制御
  • 大量点群は EPT や 3D Tiles 点群（pnts / 1.1 glTF） に変換して Cesium3DTileset / Three.js で描画すると安定

3D Gaussian Splatting（3DGS）

  • 3D 空間上の多数のガウス分布でシーンを表現するニューラル描画手法
  • 主要フォーマット
    • PLY：学習済みモデルのデファクト標準。各ガウスに位置・スケール・回転・不透明度・球面調和係数を保持
    • SPZ：Niantic 公開の圧縮形式。PLY と比べて約 10 倍小さく、Web 配信に適している
    • .splat / .ksplat / .sog：各ビューアー向けの圧縮・最適化形式
  • KASUGAI Canvas では Three.js 側で専用レンダラーを使い、オーバーレイ canvas + postRender で CesiumJS とカメラ同期を行う

地形（DEM）の扱い

  • CesiumJS TerrainProvider：KASUGAI Canvas は独自実装の GsiDemTerrainProvider（HeightmapTerrainData を返す）で地理院標高PNG (XYZ) を直接地形化する。国土地理院標高タイルは RGB → 標高値（x = 2^16R + 2^8G + B、u は標高分解能 0.01m）かつ符号付き・条件分岐形式（x < 2^23 のとき h = xu、x = 2^23 のとき NA、x > 2^23 のとき h = (x - 2^24)u）だが、この変換は gsiDecodeHeight として実装済み。表示 → 地形 タブで Re:Earth Terrain（楕円体高 / 標高）・地理院 5m+10m・地理院 1m を切替可能
  • Three.js：DEM 画像から PlaneGeometry + displacement map / 頂点シェーダーで terrain メッシュを生成する代替経路（オーバーレイ canvas 上）
  • PLATEAU 3D Tiles：3D 都市モデル（建物・地形等）を LOD 付きで配信しているので 3dtiles: 行 → Cesium3DTileset でそのまま表示
  • 生の DEM（GeoTIFF / CSV 等）は、Web Worker またはサーバー側で 標高PNG / GLB / 3D Tiles に変換してから描画
