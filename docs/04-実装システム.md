## 4. 実装システム

KASUGAI Canvas の現行実装は、ローカルPC上でRust/Axumサーバーを起動し、ブラウザ上のdeck.gl 9.3.7とThree.jsで地理空間データを描画する構成です。初期インスペクターは空で、レイヤー・ベースマップ・カメラプリセット・Info・凡例はインスペクター設定でのみ追加されます。

## 実装の全体像

処理は次の順序で構成されます。

1. Rust/Axumが`web`配下の画面と設定APIを配信する
2. インスペクター設定からレイヤー、ベースマップ、カメラプリセットを生成する
3. deck.glがTerrain、XYZ、GeoJSON、3D Tilesを同一の地図ビューへ配置する
4. 必要なXYZ・GeoJSONへ`TerrainExtension`を適用して地形へドレープする
5. Three.jsがdeck.glと共有するWebGLコンテキストへ補助3Dモデルを描画する

## レイヤーと描画順

| 種類 | 実装 | 表示方法 |
|------|------|----------|
| Terrain | deck.gl `TerrainLayer` | 選択したDEMを`Terrain (DEM表示)`で表示 |
| Base map | `TerrainLayer`のテクスチャ、または`TileLayer` | Terrain表示中はDEMテクスチャ、OFF時は通常タイル |
| XYZ | `TileLayer` + `BitmapLayer` | 設定により追加。ドレープ対象に設定可能 |
| GeoJSON | `GeoJsonLayer` | 設定により追加。ドレープ対象に設定可能 |
| 3D Tiles | `Tile3DLayer` | 設定により追加。ドレープ地形ソースに設定可能 |

初期インスペクターは空です。XYZ、GeoJSON、3D Tiles、Base mapはインスペクター設定を登録して追加します。

### レイヤー操作

レイヤーパネルの各行はドラッグ＆ドロップで並べ替えられます。並べ替えた順序は、同じ画面内のdeck.glレイヤー描画順へ反映されます。表示・非表示の切替や排他グループの動作は並べ替え後も維持されます。

## 地形、ドレープ、高さ基準

DEMの選択、Terrainの表示、ドレープ対象地形、ドレープ適用先は、それぞれ独立した設定です。処理は次の順序で決定します。

1. `DEM`でTerrain表示に使うDEMを選ぶ
2. `ドレープ対象地形`のDEM／3D Tilesから、表示中で利用可能な地形を選ぶ
3. `ドレープを適用するレイヤー`でONのXYZ・GeoJSONだけへ、選択した地形を適用する
4. Base mapはこの処理に含めず、常にDEMのテクスチャとして表示する

| 設定UI | 役割 | 他の設定への影響 |
|---|---|---|
| `DEM` | Terrain表示に使うDEMを選ぶ | デフォルトはRe:Earth Terrainの楕円体高版（描画ズーム19）。Terrarium DEM（AWS、ズーム15）とRe:Earth Terrainの標高版も選択可能。DEMを追加する場合はこの一覧へ登録する |
| `Terrain (DEM表示)` | 選択したDEMの`TerrainLayer`を表示する | DEMをドレープ対象として使うにはONが必要。3D Tilesの表示・選択は変更しない |
| `ドレープ対象地形` | DEMと3D Tilesを個別にドレープ面へ登録する | DEM・3D Tilesは初期状態でON。両方をONにすると、利用可能な両方をドレープ面にする |
| `ドレープを適用するレイヤー` | XYZ、GeoJSONの各レイヤーへ`TerrainExtension`を付与する | XYZ・GeoJSONは初期状態でON。ONのレイヤーだけをドレープする。地形ソース自体の表示は変更しない |

| ドレープ対象地形 | 有効になる条件 | ドレープ面 |
|---|---|---|
| DEM | `Terrain (DEM表示)`がON | 表示中のDEM |
| 3D Tiles | URLを持つ3D Tilesレイヤーが1つ以上表示中 | 表示中の3D Tiles |
| DEMと3D Tiles | 両方をONにし、それぞれの有効条件を満たす | 条件を満たすDEMと3D Tilesの両方 |
| どちらもOFF | なし | 適用レイヤーは通常表示 |

TerrainをONにした場合、Base mapはTerrainLayerの下地テクスチャとして描画し、TerrainExtensionのドレープ対象には含めません。その後に登録順のXYZ・GeoJSONをドレープします。TerrainをOFFにした場合は、Base mapを通常のタイルレイヤーとして先頭に表示します。ドレープ状態の切替時は対象レイヤーを再生成するため、以前のドレープ描画は残りません。

XYZタイルはカメラの最大ズームz25を初期上限として取得し、404応答を利用してURLテンプレートごとの最終取得ズームを学習します。z25で404ならz24、そこでも404ならz23というように上限を段階的に下げ、404になったズームの一つ下を最終取得ズームとします。それより高いズームでは直近の取得済みタイルを`best-available`で継続表示します。

### 高さ基準

Terrainと3D Tilesは、高さ基準を揃えなければ数十mの上下ずれが生じます。データセットごとに高さ基準を確認してDEMを選択します。

| データ | 高さ基準 | 選択するDEM |
|---|---|---|
| 元のPLATEAU CityGML | 東京湾平均海面基準の標高（JGD2011 / EPSG:6697） | 標高基準のDEMを使用 |
| Re:Earth配信のPLATEAU 3D Tiles | WGS84楕円体からの高さ | `Re:Earth Terrain (楕円体高 / WGS84)` |
| WGS84楕円体高で作成されたその他の3D Tiles・Cesium地形 | WGS84楕円体からの高さ | `Re:Earth Terrain (楕円体高 / WGS84)` |
| 高さ基準が不明な3D Tiles | データ仕様またはtilesetのメタデータを確認する | 確認後に上記いずれかを選ぶ |

Re:Earth TerrainはTerrarium形式の512×512ピクセル・24bit RGB PNGで配信され、`height = R × 256 + G + B / 256 - 32768`でメートル単位の高さを復元します。`elevation`は平均海面基準の標高、`ellipsoid`はEGM2008ジオイド高を加えたWGS84楕円体高です。サービスはCloudflare WorkersとR2でオンデマンドにタイルを生成し、実装コードはMITライセンスです。TerrainLayerには512pxタイルとして設定します。

Re:EarthのTileJSONが公開するDEMの最大ズームは14ですが、高ズーム要求には親DEMを切り出して再サンプリングしたタイルを返します。アプリケーションはカメラを-20〜25、DEMタイル取得を-20〜20まで扱います。地図中心付近のDEM標高をサンプルし、MapViewの中心高度へ反映することで、高ズーム時もカメラが標高0m基準の地形へ潜らないようにします。ただし、14を超える範囲で標高の実測解像度が増えるわけではありません。表示中は地図右下へ`Re:Earth Terrain · Mapterhorn (CC BY 4.0)`を表示します。

## インスペクター設定

設定タブは、Re:Earth GeoSuite形式の設定を登録するための入力場所です。Tile専用タブは設けず、タイルを含むレイヤー定義はすべて設定タブへ集約しています。

設定タブのテキスト欄では、Re:Earthプラグイン互換の行形式を使用します。

```text
3dtiles: 名称 | tileset.json | off
geojson: 名称 | data.geojson
xyz: OpenStreetMap | https://tile.openstreetmap.org/{z}/{x}/{y}.png
base: 表示名 | {z}/{x}/{y}.png | attribution
cam: 東京駅 | 35.653108 | 139.761449 | p=-30 | d=348.5
background: #ffffff
info: https://example.com/info.html
legend: 凡例 | https://example.com/legend.jpg
```

「登録」を押すと、XYZ・GeoJSON・3D Tilesレイヤー、ベースマップ、カメラプリセット、背景色、Info、凡例へ反映されます。ベースマップ選択欄では常に「ベースマップなし」を選べます。XYZ・GeoJSON・3D Tilesはインスペクターの定義が正本であり、記載されていない既存レイヤーは削除されます。`off`または`false`を指定したレイヤーは初期非表示になります。

レイヤー名を`グループ名/レイヤー名`または`グループ名\レイヤー名`と書くと、レイヤーパネルでグループ化して表示されます。`//`または`\\`で区切ったグループは排他グループとなり、同じグループ内で一つだけ表示できます。ドラッグ＆ドロップによる並べ替えは同じグループ内で行えます。

Search、Share、Shadow、Attrも各タブから利用できます。検索は`yahooAppId:`が設定されている場合はYahoo APIを使用し、未設定時はOpenStreetMap Nominatimを使用します。

パネル、ベースマップ選択、ナビゲーションツールバーの操作は地図操作より優先されます。これらの領域でのクリック、ホイール、マウス・タッチ操作、ドラッグは地図へ伝播しません。パネル内ではスクロールと文字選択も可能です。地物を選択した場合は属性情報だけを更新し、表示中のタブは自動変更しません。

### 設定できる項目

| 行 | 設定内容 |
|----|----------|
| `layer:` | 既存レイヤーの表示状態。`off` / `false`で非表示 |
| `xyz:` | XYZタイルレイヤーの名称、URL、初期表示状態 |
| `base:` | BASEMAP選択欄に表示するベースマップ、URL、出典 |
| `3dtiles:` | 3D Tilesレイヤーの名称、tileset URL、初期表示状態 |
| `geojson:` | GeoJSONレイヤーの名称、URL、初期表示状態 |
| `background:` | 背景色 |
| `info:` | Infoタブに埋め込むHTMLのURL |
| `cam:` | カメラプリセット。緯度・経度・高度・傾き・方位 |
| `legend:` | 凡例タブに表示する画像URL |
| `yahooAppId:` | Searchタブで使用するYahoo検索APIのApp ID |

### 設定例

```text
layer: 地理院タイル 標準地図 | off
xyz: OpenStreetMap | https://tile.openstreetmap.org/{z}/{x}/{y}.png
base: OpenStreetMap | https://tile.openstreetmap.org/{z}/{x}/{y}.png | OpenStreetMap contributors
3dtiles: 建物LOD1 | https://example.com/tileset.json | off
geojson: 行政区域 | https://example.com/area.geojson
background: #ffffff
info: https://example.com/info.html
cam: 東京駅|35.653108|139.761449|h=2200.6|p=-30|d=348.5
legend: 凡例|https://example.com/legend.png
yahooAppId: YOUR_APPID
```

設定行は順不同です。各レイヤー行の`|off`または`|false`で初期非表示、`|on`または`|true`で初期表示になります。

## カメラ、ズーム、URL

カメラ状態はdeck.glの`viewState`で管理します。

| パラメータ | 内容 |
|------------|------|
| `longitude` | 経度 |
| `latitude` | 緯度 |
| `zoom` | ズーム |
| `pitch` | 傾き |
| `bearing` | 方位 |

これらはURLクエリへ保存されるため、URLの共有・ブックマークで同じ視点を復元できます。

### ズームとDEM

カメラのズーム上限はZ25、DEMタイルの取得上限はZ20です。東京付近のZ25はおよそ縮尺1:14相当ですが、Re:Earth Terrainの実測解像度は公開上限のZ14相当であり、それを超える表示は補間・拡大です。

高ズーム時にカメラが標高0m基準の地形へ潜らないよう、地図中心付近のDEMをサンプルして`MapView.position`の中心高度へ反映します。DEMの取得に失敗した場合は、直前のカメラ状態を維持してエラーをコンソールへ出力します。

## 起動・配布

```powershell
python run.py
python run.py -B
python run.py --release
```

`-B`ではRustのリリースビルドを実行し、`download\kasugai_canvas.zip`を作成します。
