## 4. 実装システム

KASUGAI Canvas の現行実装は、ローカルPC上でRust/Axumサーバーを起動し、ブラウザ上のdeck.gl 9.3.7とThree.jsで地理空間データを描画する構成です。初期インスペクターは空で、レイヤー・ベースマップ・カメラプリセット・Info・凡例はインスペクター設定でのみ追加されます。

## 実装済みレイヤー

| 種類 | 実装 | 初期状態 |
|------|------|----------|
| 地形 | deck.gl `TerrainLayer` | ON |
| XYZラスタータイル | `TileLayer` + `BitmapLayer` + `TerrainExtension` | ベースマップ・追加XYZともドレープ対応 |
| GeoJSON | `GeoJsonLayer` + `TerrainExtension`（drape） | ON・選択した地形へドレープ |
| 3D Tiles | `Tile3DLayer` | 設定により切替 |
| Three.jsモデル | Three.js共有コンテキスト | ON |

PLATEAU千代田区LOD1、東京都行政区域GeoJSON、国土地理院タイル、OpenStreetMapを初期設定として登録しています。

レイヤーパネルの各行はドラッグ＆ドロップで並べ替えられます。並べ替えた順序は、同じ画面内のdeck.glレイヤー描画順へ反映されます。表示・非表示の切替や排他グループの動作は並べ替え後も維持されます。設定タブの「ドレープ対象地形ソース」で、ドレープ先として国土地理院DEM、表示中の3D Tiles、両方、ドレープしない、を選択できます。「ドレープを適用するレイヤー」ではXYZ、Base map、GeoJSONを個別に選択できます。Base mapへのドレープはデフォルトでOFFです。選択した地形ソースは`operation: "terrain+draw"`で先に描画され、選択したレイヤーは`TerrainExtension`の`drape`モードでその表面に表示します。地形ソースを切り替えると描画レイヤーも再生成し、前のドレープキャッシュを保持しません。

## インスペクター設定

設定タブは、Re:Earth GeoSuite形式の設定を登録するための入力場所です。Tile専用タブは設けず、タイルを含むレイヤー定義はすべて設定タブへ集約しています。

設定タブのテキスト欄では、Re:Earthプラグイン互換の行形式を使用します。

```text
3dtiles: 名称 | tileset.json | off
geojson: 名称 | data.geojson
xyz: OpenStreetMap | https://tile.openstreetmap.org/{z}/{x}/{y}.png
base: 表示名 | {z}/{x}/{y}.png | attribution
cam: 東京駅 | 35.653108 | 139.761449 | p=-30 | d=348.5
background: #ffffff
info: https://example.com/info.html
legend: 凡例 | https://example.com/legend.jpg
```

「登録」を押すと、XYZ・GeoJSON・3D Tilesレイヤー、ベースマップ、カメラプリセット、背景色、Info、凡例へ反映されます。ベースマップ選択欄では常に「ベースマップなし」を選べます。XYZ・GeoJSON・3D Tilesはインスペクターの定義が正本であり、記載されていない既存レイヤーは削除されます。`off`または`false`を指定したレイヤーは初期非表示になります。

レイヤー名を`グループ名/レイヤー名`または`グループ名\レイヤー名`と書くと、レイヤーパネルでグループ化して表示されます。`//`または`\\`で区切ったグループは排他グループとなり、同じグループ内で一つだけ表示できます。ドラッグ＆ドロップによる並べ替えは同じグループ内で行えます。

Search、Share、Shadow、Attrも各タブから利用できます。検索は`yahooAppId:`が設定されている場合はYahoo APIを使用し、未設定時はOpenStreetMap Nominatimを使用します。

パネル、ベースマップ選択、ナビゲーションツールバーの操作は地図操作より優先されます。これらの領域でのクリック、ホイール、マウス・タッチ操作、ドラッグは地図へ伝播しません。パネル内ではスクロールと文字選択も可能です。地物を選択した場合は属性情報だけを更新し、表示中のタブは自動変更しません。

### 設定できる項目

| 行 | 設定内容 |
|----|----------|
| `layer:` | 既存レイヤーの表示状態。`off` / `false`で非表示 |
| `xyz:` | XYZタイルレイヤーの名称、URL、初期表示状態 |
| `base:` | BASEMAP選択欄に表示するベースマップ、URL、出典 |
| `3dtiles:` | 3D Tilesレイヤーの名称、tileset URL、初期表示状態 |
| `geojson:` | GeoJSONレイヤーの名称、URL、初期表示状態 |
| `background:` | 背景色 |
| `info:` | Infoタブに埋め込むHTMLのURL |
| `cam:` | カメラプリセット。緯度・経度・高度・傾き・方位 |
| `legend:` | 凡例タブに表示する画像URL |
| `yahooAppId:` | Searchタブで使用するYahoo検索APIのApp ID |

### 設定例

```text
layer: 地理院タイル 標準地図 | off
xyz: OpenStreetMap | https://tile.openstreetmap.org/{z}/{x}/{y}.png
base: OpenStreetMap | https://tile.openstreetmap.org/{z}/{x}/{y}.png | OpenStreetMap contributors
3dtiles: 建物LOD1 | https://example.com/tileset.json | off
geojson: 行政区域 | https://example.com/area.geojson
background: #ffffff
info: https://example.com/info.html
cam: 東京駅|35.653108|139.761449|h=2200.6|p=-30|d=348.5
legend: 凡例|https://example.com/legend.png
yahooAppId: YOUR_APPID
```

設定行は順不同です。各レイヤー行の`|off`または`|false`で初期非表示、`|on`または`|true`で初期表示になります。

## カメラとURL

カメラ状態はdeck.glの`viewState`で管理します。

| パラメータ | 内容 |
|------------|------|
| `longitude` | 経度 |
| `latitude` | 緯度 |
| `zoom` | ズーム |
| `pitch` | 傾き |
| `bearing` | 方位 |

これらはURLクエリへ保存されるため、URLの共有・ブックマークで同じ視点を復元できます。

## 起動・配布

```powershell
python run.py
python run.py -B
python run.py --release
```

`-B`ではRustのリリースビルドを実行し、`download\kasugai_canvas.zip`を作成します。
