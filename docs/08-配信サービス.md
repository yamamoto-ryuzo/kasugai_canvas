## 8. 配信サービス

### Re:Earth CMS の位置づけ

- **メイン**：属性・プロジェクト管理・検索API
- **オープンソース・セルフホスト**可能（ローカル/オンプレ対応）
- PLATEAU / GIS データの管理・メタデータ付与に強い

### データ種別ごとの配信構成

| データ種別 | 配信サービス | Re:Earth CMS の役割 |
|-----------|-------------|--------------------|
| 属性・プロジェクト管理 | **Re:Earth CMS** | メインデータ管理 |
| 2D Buffers (GeoArrow/FlatBuffers) | Re:Earth CMS or S3互換 | アセット保存 |
| 広域 3D Tiles / 点群 | **S3/MinIO + CDN** | URL参照 |
| 2D MVT / 地理院タイル | **Martin / Tegola** | 外部API連携 |

### ハイブリッド配信フロー

```text
データ入力/管理
├── 現場メタデータ ──> Re:Earth CMS
├── 2D図面(.arrow) ──> Re:Earth CMS / S3
└── 3D Tiles/点群 ───> S3/MinIO
         ↓ (URL/API)
kasugai (deck.gl)
    ↓
ゼロコピーで VRAM 転送・爆速描画
```
