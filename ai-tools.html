KASUGAI Canvas v5.23.0

AI ツール仕様 — 内蔵AIが制御できる全50ツールの定義

🤖 概要

内蔵AI（Gemini または OpenAI互換プロバイダの function/tool calling）が呼び出せるツールは web/app.js の CHAT_TOOLS に宣言された 50 種です。このページはその宣言の仕様ミラーであり、CHAT_TOOLS を変更したらここも更新してください。概要・体験説明は V3: AI 連携、キー供給経路は Google 連携・AI を参照。

実行モデル：ユーザーの発言 → AI がツール呼び出しを返す → ブラウザが kasugaiApi 経由で実行 → 結果を AI に返す、の function calling ループ（OpenAI互換選択時は宣言を OpenAI tools 形式へ変換し、往復結果は tool メッセージとして返送）。ツール実行の上限往復数は既定10（管理 → AI → チャット の「ツール実行の上限往復数」または AI への指示で setToolMaxSteps により 1〜20 で変更可）。上限到達時はユーザーに継続確認が出て、承認なら同じ往復数を1枠追加して続行、拒否なら中断します。推論はすべてブラウザ側。破壊的ツールは実行前に確認ダイアログを挟み、最終判断はユーザーにあります。

提供条件（activeChatTools で絞り込み）

条件対象ツール

📷 カメラ・視点（5）

ツール引数（＊=必須）説明
flyTolatitude*, longitude*, height, pitch, headingカメラを指定座標へ移動。height/pitch 省略時はドローン視点（対象地上+200m・-30°）。pitch=-90 で真上俯瞰
flyToFeaturelatitude*, longitude*, height, pitch, heading指定座標が画面中央に来るよう後退補正して移動。地点・地物を見せる場合はこちら
flyToPresetname*登録済みカメラプリセット名で移動（listCameraPresets で確認）
listCameraPresetsなし登録済みカメラプリセット名の一覧を取得
getCameraなし現在のカメラ位置（緯度・経度・高さ・方位・ピッチ）を取得

🗂 レイヤー（7）

ツール引数説明
listLayersなし登録レイヤー一覧（名前・表示状態）を取得
setLayerVisiblename*, visible*レイヤー名指定で表示/非表示を切替
focusLayername*レイヤー名または ID 指定で全体が収まるようカメラ移動。非表示レイヤーは自動表示してから移動
addLayertitle*, target*, type, optionsベクターレイヤーを追加して即適用。type: geojson(既定)/layer/geoparquet/flatgeobuf/gpkg/duckdb/sql。target は URL または DATA/ 相対パス（sql は SELECT 文）。options は where=/limit=/format=/bbox=auto/proxy=on/render=primitive/attr=出典 等を | 区切りで指定。http(s) URL は実行前に実在確認され、到達不能なものは拒否される。インスペクター設定に反映されるためユーザー明示時のみ
addGeoJsonLayertitle*, url*GeoJSON レイヤーを URL 指定（DATA/ 相対パスまたは外部 URL）で追加して即適用。http(s) URL は実行前に実在確認され、到達不能なものは拒否される。他形式は addLayer
applyInspectortext*インスペクターの設定テキスト（.kasc 形式）を登録・適用。新規追加されるデータレイヤー行の http(s) URL は適用前に実在確認され、到達不能なものがあると拒否される。設定全体が上書きされるためユーザー明示時のみ。書式は .kasc 設定仕様
exportInspectorなし現在の設定を .kasc ファイルとしてエクスポート（ダウンロード）

🌍 ベースマップ・地形・効果（6）

ツール引数説明
listBasemapsなし選択可能なベースマップ一覧と現在の選択を取得

ツール引数説明

🔍 検索（4）

ツール引数説明
searchLocationquery*, provider住所・地名・施設名を検索し候補（名称・住所・緯度経度）を返す。provider: gsi/google/places/yahoo（省略時は検索タブの選択。google=Geocoding+Places ハイブリッド、places=Places のみ）。結果へは flyTo/flyToFeature で移動
vectorSearchquery*読み込み済みベクトルデータの属性を検索し、該当する属性名・値・位置を返す。結果の緯度経度へは flyToFeature で移動
searchPlaces 🔑query*Google Places API（テキスト検索）で施設・店舗・観光地等を検索。Maps API キー設定時のみ
openStreetView 🔑latitude*, longitude*指定座標の Google ストリートビューを別タブで開く。Maps API キー設定時のみ

🔑 = Google Maps API キー必須（管理 → Google Maps で設定）

📄 共有・資料生成（3）

ツール引数説明
getShareUrlなし現在のカメラ位置・プロジェクトを含む共有 URL を取得
buildShareUrllatitude*, longitude*, height, pitch, heading, project指定座標・視点の共有 URL を組み立てる。省略引数は現在視点を使用。資料の各節に視点別パーマリンクを埋め込む用途
showReporttitle*, content*, format生成した資料をモーダル表示＋ダウンロード可能にする。「資料を作って」等の指示に対し、平面・内容・解決案の構成で content に本文（Markdown/HTML、各節に視点パーマリンクを含める）

架空・サンプル GeoJSON を生成する場合は、feature の properties に dataSource・generatedAt・aiGenerated:true の出典スタンプが必須付与されます（システム指示）。

ツール引数説明

🧩 コード実行・プラグイン（7）

ツール引数説明
runCodecode*ブラウザ内サンドボックスで JavaScript を実行し戻り値と console 出力を返す。データ加工・集計・座標計算に。api.<関数名>（kasugaiApi と同じ）で地図操作が非同期呼出し可。DOM・localStorage・外部 fetch は不可
savePluginid*, code*, name, layer, enableプラグインをブラウザ内 IndexedDB に保存・有効化する自己拡張ツール。code は export async function init(api, manifest){} 形式の ES モジュール。layer 指定でプラグイン専用レイヤー自動登録。保存前にコード確認ダイアログ。既存 id は上書き＋再読み込み
listPluginsなし同梱・保存済みプラグイン一覧（id/name/source/enabled/lastError）
getPluginCodeid*保存済みプラグインのコードと設定を取得（修正→ savePlugin 再保存の修正ループ用）
removePluginid*保存済みプラグインを削除。確認ダイアログあり
setPluginEnabledid*, enabled*保存済みプラグインの有効/無効切替
publishPlugin 💻id*保存済みプラグインを配布用 PLUGIN/ に書き込み全利用者に公開（ローカルサーバー版のみ・取り消しは開発者作業）。確認ダイアログあり

プラグインの昇格ルート：AI 生成 → IndexedDB（ブラウザローカル草稿）→ .kasp エクスポート可 → レビュー後にローカル版で PLUGIN/ へ公開。
