1. ローカル認証（local）

概要

最小限のローカル向け認証（テスト・実験用）です。web/PLUGIN/auth-local/auth.js 内の定数と同じ ID/PASS を入力すると起動します。

起動と設定

web/auth-methods.json の control を 1 に設定すると、この認証方式が選択されます。

{
  "control": 1
}

ブラウザで http://127.0.0.1:8510/ を開くと、ログイン画面が表示されます。

ID/PASS の設定

web/PLUGIN/auth-local/auth.js の以下の定数を編集してください。

const EXPECTED_USER = "admin";
const EXPECTED_PASS = "admin";

初期値: ユーザーID admin、パスワード admin

セキュリティ上の注意

  • 保護できるもの：簡易な起動制御（ID/PASS の平文照合）
  • 保護できないもの：HTML/JS/CSS や DATA/ 内のファイル、定数の読み取り
  • 利用場面：動作確認・実験用
  • 注意：平文で管理されるため、本番や公開環境には不向きです
