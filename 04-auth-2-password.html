2. 簡易パスワード認証（password）

概要

環境変数やクラウドが不要で、JS ファイル内のハッシュと比較するだけの簡易な起動制御です。公開用ではありません。GLWAN など限定的な環境やテスト用途に限定してください。インターネットや社内共有サーバーで公開する場合は 3. Cloudflare Pages 認証（cloudflare） を使用してください。

起動と設定

web/auth-methods.json の control を 2 に設定すると、この認証方式が選択されます。

{
  "control": 2
}

ブラウザで http://127.0.0.1:8520/ を開くだけで起動します。

ID/PASS の設定

web/PLUGIN/auth-password/auth.js の以下の定数を編集してください。

const EXPECTED_USER = "admin";
const EXPECTED_SALT = "2tr4Cnrn5LXfo6fpf7ozNg==";
const EXPECTED_HASH = "67mzCzSXZtPm1xNbLmYgPN+ME4F974mZ+qqIxKOu5Zg=";

初期値: ユーザーID admin、パスワード admin

ハッシュ生成

新しい SALT / HASH を生成する例です。

python -c "import base64,secrets,hashlib; s=secrets.token_bytes(16); h=hashlib.pbkdf2_hmac('sha256',b'USER:PASS',s,100000,32); print(base64.b64encode(s).decode()); print(base64.b64encode(h).decode())"

セキュリティ上の注意

  • 保護できるもの：起動時の ID/PASS 確認
  • 保護できないもの：HTML/JS/CSS や DATA/ 内のファイル、ハッシュの読み取り
  • 利用場面：GLWAN など限定的な環境・テスト用途（公開不可）
  • 注意：真のセキュリティには向いていません。完全な保護が必要な場合は cloudflare 方式を使用してください
