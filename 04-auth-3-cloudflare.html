3. Cloudflare Pages 認証（cloudflare）

概要

Cloudflare Pages Functions を使ったサーバーレス ID/PASS 認証です。認証後に暗号化された .kasc.enc を自動復号してアプリを起動します。安全な本番運用に推奨します。

起動と設定

web/auth-methods.json の control を 3 に設定すると、この認証方式が選択されます。

{
  "control": 3
}

ブラウザで https://<your-site>/ を開くだけで起動します。

環境変数

Cloudflare Pages ダッシュボードまたは .dev.vars に以下を設定します。

KASUGAI_AUTH_USER  = ユーザーID
KASUGAI_AUTH_PASS  = パスワード
KASUGAI_DATA_KEY   = .kasc 復号用 AES 鍵（base64）

.kasc 暗号化手順

  1. KASUGAI_DATA_KEY を準備します。
  2. 以下のコマンドで .kasc を暗号化します。
python tools/encrypt_kasc.py "<KASUGAI_DATA_KEY>" "web/projects/<project>/kasugai_canvas.kasc"

生成された .kasc.enc をデプロイに含め、元の .kasc は削除してください。

セキュリティ上の注意

  • 保護できるもの：アプリ起動制御、.kasc 設定情報（ID/PASS 認証後の復号鍵でブラウザ内復号）
  • 保護できないもの：HTML/JS/CSS 等の静的ファイル、DATA/ 内の画像・GeoJSON 等
  • 利用場面：安全な本番運用
  • 注意：完全なファイルアクセス制御が必要な場合は、Cloudflare Functions や R2 等でファイル配信を制御してください
