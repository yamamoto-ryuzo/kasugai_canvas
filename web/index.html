      共有

      DEMテクスチャー：DEMで作った地形メッシュにBase map画像を貼る表示。
      ドレープ：XYZ・GeoJSONなどのレイヤーを地形表面の起伏に沿わせて貼る表示。

      高さ基準：「楕円体高 / WGS84」は3D地球・PLATEAU等の3D Tilesと整合します。「標高 / 平均海面基準」「地理院(TP基準=東京湾平均海面)」は楕円体高より約30〜40m低く表示されます(3D Tilesが地面に埋もれて見える場合があります)。「地理院」は日本域のみ有効です。

      ドレープ対象地形 ドレープを適用するレイヤー

      CesiumJS 1.145 の GeoJsonPrimitive を使い、GeoJSON を高品質・高速に地形や 3D Tiles にドレープします。有効時はベクター検索の対象外になります。

      断面クリップ

      カメラ中心に断面を作成します。カメラ位置を移動してから実行してください。

      CesiumJS 3D Tiles 描画パラメータを調整します。値を変えると 3D レイヤーが再読み込みされます。

      値を大きくすると読み込むタイル数が減り、描画が軽快になります。小さいほど詳細です。

      3D Tiles のキャッシュメモリ上限です。小さいとタイルの再読み込みが増えます。

      ON にすると遠景タイルを自動で粗くし、カメラ高度が高い場面で軽快になります。

      ON にすると子タイルの範囲から不要な親タイルを除外し、描画負荷を下げます。

      ON にすると最も詳細なリーフタイルを優先的に読み込みます。重くなりやすいです。

      ON にすると中間 LOD を読み飛ばし、素早く目的の解像度のタイルへ到達します。

      CesiumJS の表示効果を調整します。

      Gemini API（AIチャット用）の設定です。Google AI Studio で発行したキーを入力してください。

      セキュリティについて：キーはブラウザの localStorage にのみ保存され、送信先は Google の API エンドポイント（HTTPS）のみです。ただし API 呼び出し時にキーがリクエストURLに含まれるため、このPCを操作する人・ブラウザ拡張機能・ページ上のスクリプトからは参照可能です。ローカル・個人利用を前提とし、公開サーバーへの設置や第三者との共有は避けてください。Google Cloud 側でキーに「Generative Language APIのみ」等のAPI制限をかけることを推奨します。

      Google Maps Platform の API キーです。Google Cloud Console で発行したキーを入力してください。ジオコーディング・Places・Photorealistic 3D Tiles 等の地図機能で使用します。

      セキュリティについて：キーはブラウザの localStorage にのみ保存されます。Gemini キーとは別キーを推奨します。Google Cloud 側で「Map Tiles API のみ」等のAPI制限と、可能であればHTTPリファラー制限をかけてください。従量課金のため、予算アラートの設定を推奨します。

      表示

      ONにすると保存済みの Maps API キーで Google のフォトリアル3Dタイルをレイヤ一覧へ自動追加します。Map Tiles API の従量課金が発生します。

      AIチャットが生成したプラグイン（このブラウザの IndexedDB に保存）を管理します。有効化したプラグインは起動時に自動で読み込まれます。公開するプラグインは PLUGIN/ フォルダと plugins.json へ登録します。
