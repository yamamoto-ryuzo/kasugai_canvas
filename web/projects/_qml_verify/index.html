KASUGAI Canvas プロジェクト — kasugai_canvas.kasc

このエクスポート物（.kasc+DATA/・起動HTML）は3つの経路で表示できます。

1KASUGAI Canvas（主・統合プレイヤー）で開く

起動中の Canvas アプリ（127.0.0.1:8510）にプロジェクトを登録して開きます。アプリ未起動なら起動してから再読み込みしてください。

  • Canvas に接続しています…

2ローカル HTTP 配信でブラウザ即表示

QGIS プラグインの HTTP サーバーが、インストール済み Canvas の web/ と DATA/ を配信します（要 Canvas インストール＋サーバー稼働）。

    このページを http://localhost:8089/export-data/ 経由で開くとリンクが有効になります。

    3サーバレス WEB 配信

    ホスト版エンジン（GitHub Pages）で開きます。データはプラグインサーバー稼働中のみ有効です。
    常時公開する場合は このフォルダ一式＋エンジン（web/ の中身）を同じ静的ホストへアップし、下の起動HTMLを使ってください（エンジンを自動探索します）。

      パッケージ配置後の起動ページ: cesium.html / maplibre.html / openlayers.html / leaflet.html / gsimaps.html / navara.html （各HTML内の CANVAS_BASE でエンジン位置を指定可）

      パッケージ ZIP

      エクスポート一式（.kasc+DATA/+起動HTML）の ZIP です。静的ホストへの配置や Re:Earth geo_suite の qgis: 取り込みに使えます。
      プラグインの HTTP サーバー経由で開いている場合、クリック時にその場で生成してダウンロードします。
