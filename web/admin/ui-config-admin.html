「サーバーに保存」はローカルサーバー起動時のみ有効です。「ブラウザに保存」はこのブラウザの localStorage に書き込み、同じ配信元のエンジン起動時にファイルより優先して適用されます（CDN でも使えます）。別環境へ配る場合はダウンロード（<engine>.ui.config.json で出力）して <engine>/ フォルダへ ui.config.json として配置してください。反映にはページ再読み込みが必要です。
