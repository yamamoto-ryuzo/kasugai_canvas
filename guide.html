KASUGAI Canvas v5.0.0

使い方・インストール — 起動・プロジェクト構成・配布と公開

🔗 インストール

配布 ZIP / インストーラー

最新のビルドは download/ フォルダから直接ダウンロードできます。

DOWNLOAD: ポータブル ZIP DOWNLOAD: インストーラー ZIP
  1. ポータブル版は kasugai_canvas.zip を任意のフォルダに展開。インストーラー版は kasugai_canvas_setup.zip を展開して kasugai_canvas_setup.exe を実行
  2. インストーラーのウィザードに従って C:\kasugai\kasugai_canvas へインストール
  3. 同梱の kasugai_canvas.exe を実行するか、ショートカットから起動
  4. 既定でブラウザが開き、KASUGAI Canvas が起動します

GitHub Releases からも同じファイルを取得できます。

リリースビルド

python run.py -B

配布用 ZIP（kasugai_canvas.exe + web/ + projects/）と、NSIS が利用可能な場合はインストーラーを download\ に作成します。既定のインストール先は C:\kasugai\kasugai_canvas です。

自動更新

Rust サーバー起動時は、設定パネルから最新リリースの確認・自動更新が行えます。更新時は EXE を自動的に差し替えて再起動します。

📖 起動方法

起動方法（通常のHTTPサーバー）

cd web
python -m http.server 8520

web/ をドキュメントルートに置くだけです。ブラウザで http://127.0.0.1:8520/ を開いてください。

起動方法（Rustサーバー / 開発）

cargo run --manifest-path server\Cargo.toml
# または
python run.py            # 開発起動
python run.py --release  # リリース版を起動

ブラウザで http://127.0.0.1:8510/ を開いてください。ポートは KASUGAI_CANVAS_PORT 環境変数で変更できます。インスペクター設定は projects/<project>/kasugai_canvas.kasc に保存されます。

📖 使い方

基本の流れ

  • 設定は projects/<project>/kasugai_canvas.kasc に記述します。
  • ローカルデータは projects/<project>/DATA/ 以下に置き、設定から相対パスで参照できます。
  • 「エクスポート(.kasc)」ボタンで変更をダウンロードし、設定ファイルと差し替えて保存してください。
  • web/ ディレクトリは通常の HTTP サーバーにそのまま配置できます。

プロジェクト構成

web/                    # フロントエンド資産(静的配信のみで動作)
├─ index.html / app.js / styles.css
└─ projects/
   ├─ projects.json      # プロジェクト一覧 [{"id":"...","title":"..."}]
   └─ <project_id>/
      ├─ project.json     # 表示名等
      ├─ kasugai_canvas.kasc  # インスペクター設定
      └─ DATA/            # ローカルGeoJSON・3D Tiles・画像等

設定内の相対パス（例: DATA/sample.geojson）は projects/<project_id>/DATA/ に解決されます。Rustサーバー使用時は同構成の projects/ をサーバーと同階層に配置します。

設定の保存

静的サーバーでは設定をサーバーに保存しません。インスペクターの「エクスポート(.kasc)」でダウンロードし、対象プロジェクトの kasugai_canvas.kasc と差し替えてください。

インスペクター設定

xyz: OpenStreetMap | https://tile.openstreetmap.org/{z}/{x}/{y}.png
base: 地理院タイル 全国最新写真 | https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg | 出典：国土地理院 | max=18
cam: 東京駅 | 35.653108 | 139.761449 | h=2200.6 | p=-30
info: https://example.com/project-info.html

1 行 種類: 値 形式でレイヤー、ベースマップ、カメラ、Info、凡例等を記述します。完全な書式・オプション・ローカルファイル追加手順は .kasc 設定仕様 を参照してください。

FLY 機能（KASUGAI 独自追加機能）

  1. kasugai_canvas.kasc に fly_geojson: ルート名 | URL | speed=10 | height=100 | pitch=-30 を追加
  2. ナビゲーションツールバーから Fly モードに切り替え、ドロップダウンでルートを選択
  3. マウスホイール / キー + / - で速度、キー Q / E で高さ補正を調整
  4. Orbit モードで Draw タブから右クリックで点を追加、右ダブルクリックでルート描画終了→ブラウザ IndexedDB に自動保存されドロップダウンに追加
  5. 「取込」で .geojson ファイルを IndexedDB へインポート、描画ルートを選択中は「出力」（.geojson ダウンロード）「削除」ボタンが表示。インスペクタで route:<ルート名> を参照することも可（例：fly_geojson: 名 | route:drawn_route_...）

クラウドストレージ連携（rclone・ローカルサーバーのみ）

  1. 設定 → クラウド タブを開き、rclone の検出状態を確認。未導入なら「インストール先フォルダ」（既定 C:\kasugai\rclone）を指定して「ダウンロードして配置」
  2. 「ストレージ」で種別（Box / GoogleDrive / OneDrive / Dropbox / pCloud / MEGA / WebDAV / S3）を選んで「追加」。ブラウザで OAuth 認証画面が開くので、許可後に「更新」を押すとリモート一覧に反映されます
  3. 「ルートフォルダ」に接続の起点を指定します（省略可）。フォルダパスのほか、Box の https://app.box.com/folder/…・共有リンク …/s/…、Google Drive の …/folders/…、OneDrive の ?id=… といったフォルダURLも指定できます。URL指定はフォルダID起点で接続されるため、権限や共有経路によってリモート内の見える位置が異なる環境間でも、全員が同じフォルダをルートとして参照できます
  4. 「読み取り専用 / 読み書き」を選んで「接続開始」。「ドライブ割当」（既定 K:）を指定するとエクスプローラーからも使える仮想ドライブになります（Windows のみ）
  5. レイヤーURLには cloud: スキームが使えます。geojson: 名 | cloud:フォルダ/file.geojson のように接続中ストレージのファイルを直接参照でき、HTTP Range にも対応しています
  6. 読み書きで接続中は「.kascをクラウドへ保存」で現在の設定をクラウド上に保存できます

ドライブ経由の読み書きは Windows WebClient の制約で約 50MB 超のファイルを扱えません（cloud: スキーム経由はこの制限を受けません）。この機能はローカルサーバー（local ティア）のみで有効です。

🌐 ハイブリッド配布・公開構成

KASUGAI Canvas は、ブラウザ完結の CesiumJS フロントエンドに整理されています。Rust/Axum サーバーはあくまで 最小限の静的ファイル配信で、web/ ディレクトリそのものを nginx / Apache / IIS / GitHub Pages などに置くだけで一般公開もできます。

📦 ローカル・納品

kasugai_canvas.zip または NSIS インストーラーで配布。kasugai_canvas.exe と同じ場所に web/・projects/ を配置します。

🌐 WEB 公開

web/ を静的サーバーにアップロード。同一オリジン内の projects/<id>/DATA/ を相対パスで参照できます。

🔒 読み取り専用

プロジェクトファイルは Web サーバー側の権限で書き込み禁止にできます。変更は「エクスポート(.kasc)」でローカルに落として差し替えます。

⚠️ 公開時の注意

外部 3D Tiles / GeoJSON は CORS が必要。Yahoo AppID 等の認証情報を .kasc に書くと公開サイトで漏洩します。
