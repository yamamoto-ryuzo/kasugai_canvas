概要

ID/PASS の設定は不要です。誰でもアプリを起動できます。アクセスを制限したい場合は 3. Cloudflare 認証（cloudflare） を使用してください。

利用シーン

  • アクセス制御が不要な一般公開
  • ローカル開発
  • 非公開の信頼できる環境
  • 認証機能の動作確認を気にしないケース

起動と設定

web/auth-methods.json の control を 0 に設定すると、この認証方式が選択されます。

{
  "control": 0
}

ブラウザで http://127.0.0.1:8510/ を開くだけで起動します。

資産未ログインの第三者備考

セキュリティ上の注意

  • 保護できるもの：アプリ起動制御（なし。全公開です）
  • 保護できないもの：HTML/JS/CSS 等の静的ファイル、DATA/ 内の画像・GeoJSON 等
  • 利用場面：アクセス制御が不要な一般公開、ローカル開発、非公開の信頼環境
  • 注意：一般公開する場合は、DATA/ 内のすべてのデータが誰でも閲覧可能であることを確認してください
