概要

ID/PASS の設定は不要です。誰でもアプリを起動できます。アクセス制御が不要な一般公開や非公開の信頼環境に使用します。アクセスを制限したい場合は 3. Cloudflare Pages 認証（cloudflare） を使用してください。

  • アクセス制御が不要な一般公開
  • ローカル開発
  • 非公開の信頼できる環境
  • 認証機能の動作確認を気にしないケース

起動と設定

web/auth-methods.json の control を 0 に設定すると、この認証方式が選択されます。

{
  "control": 0
}

ブラウザで http://127.0.0.1:8520/ を開くだけで起動します。

セキュリティ上の注意

  • 保護できるもの：なし（全公開）
  • 保護できないもの：アプリ、静的ファイル、DATA/ 内のデータ全般
  • 利用場面：アクセス制御が不要な一般公開、ローカル開発、非公開の信頼環境
  • 注意：一般公開する場合は、DATA/ 内のすべてのデータが誰でも閲覧可能であることを確認してください
