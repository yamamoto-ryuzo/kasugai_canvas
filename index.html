KASUGAI Canvas v4.21.0

ローカルPC・ブラウザ完結で動作する 2D/3D データ可視化システムのドキュメント

📋 概要

KASUGAI Canvas は、CesiumJS + Three.js を核とした 2D/3D データ可視化システムです。Re:Earth GeoSuite と上位互換の GIS 基本機能に加え、KASUGAI 独自の FLY 機能・AIチャット（Gemini 連携）を備えています。

v3.4.2 以降、地図タイル・検索・レイヤー取得は CesiumJS が直接行い、Rust サーバーはバージョン管理・シャットダウン・ヘルスチェック API のみ提供します。

メジャーバージョンの機能テーマ

  • V1: GIS 基本機能
  • V2: プレゼンテーション機能（Fly モード・描画ルート等）
  • V3: AI 連携
  • V4: プラグイン（認証機構）
  • V5（予約）: ANTIGRAVITY エージェント完成
▶ デモサイトを開く（インストール不要・ブラウザで即起動）

デモは GitHub Pages 上の静的配信版です。設定の保存・サーバー経由の一部機能は無効ですが、地図閲覧・Fly など主要機能はそのまま試せます。

▶ デモサイトを開く（Cloudflare Pages・認証方式3）

Cloudflare Pages 上のデモです。認証方式 3（Pages Functions + KV）で動作しており、ログイン ID／パスワードはいずれも demo です。

▶ デモサイトを開く（Cloudflare Workers・認証方式4）

Cloudflare Workers 上のデモです。認証方式 4（Worker + KV・全ファイル認証ゲート）で動作しており、未ログインでは静的ファイルも取得できません。ログイン ID は admin、パスワードは admin123 です。
