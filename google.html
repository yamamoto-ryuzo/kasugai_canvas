KASUGAI Canvas v5.1.0

Google 連携・AI — Gemini AIチャット・Maps Platform・エージェント連携

🔗 Google 連携（v6.0 へ向けた主要機能）

トップレベルの「Google」タブ（設定の右）に Google 関連機能を集約しています。Gemini による AI チャットと Google Maps Platform の地図機能を、このタブのサブタブ（Gemini / Map / エージェント）から設定・管理します。これらの Google 連携機能（AIチャット・エージェント連携・Maps Platform 各種 API）がすべて完成した時点で v6.0 をリリースする予定です。

🤖 AIチャット（Gemini）

右下の Chat パネルから Gemini API（function calling）で地図を操作。「◯◯へ飛んで」「レイヤを消して」等をAIが実行。flyTo・レイヤ切替・ベースマップ・検索・地形/効果・地下表示・断面クリップ・Flyパス・プロジェクト切替まで網羅。AI移動はドローン視点（対象地上+200m・-30°）が既定。Google → Gemini タブで API キー・モデルを設定

🗺️ Photorealistic 3D Tiles

Google → Map タブで Maps Platform API キーを設定し、「Photorealistic 3D Tiles」を ON にすると、Google のフォトリアル3Dタイルがレイヤ一覧へ自動追加され表示されます。Map Tiles API は従量課金です

🔍 Maps Platform の検索・ Places ・ Street View

Maps API キーを保存すると、住所検索タブのプロバイダに「Google」が追加されます。Geocoding API と Places テキスト検索を並列で呼ぶハイブリッド検索で、住所・施設名・キーワードのいずれにも対応します。検索結果の「SV」ボタンや「地図をクリック → Street View」でストリートビューを別タブで開き、「候補ラインを表示」で撮影済み道路の青いラインを地図上に重ねられます。AIチャットには searchPlaces（Places テキスト検索）・openStreetView（ストリートビューを別タブで開く）ツールが有効時のみ公開され、「近くのカフェを探して」「この地点のストリートビューを見せて」といった指示に対応します

🔑 API キー管理

Gemini キーは Google AI Studio、Maps キーは Google Cloud Console で発行。キーは localStorage にのみ保存され、.kasc エクスポートには含まれません

Google Cloud で有効化・キー制限への追加が必要な API:

  • Map Tiles API — Photorealistic 3D Tiles
  • Geocoding API — 検索プロバイダ「Google」（ハイブリッド検索の住所側）
  • Places API (New) — ハイブリッド検索の施設・キーワード側 / AIツール searchPlaces
  • Street View Static API — Street View のメタデータ確認（「SV」ボタン・地図クリック・AIツール openStreetView。パノラマ自体は Google マップを別タブで開くだけなので API 不要）

Geocoding / Places / Street View の Web サービス API は HTTP リファラー制限付きキーを拒否します。リファラー制限をかけたい場合は「Web サービス用キー」欄に制限なしの別キーを設定してください（Map Tiles API のみリファラー制限が有効なので、上の「Maps API キー」に制限付きキーを入れる運用が可能です）。Street View 候補ラインは Google マップ内部のカバレッジデータ（キー不要・非公式）を使用します

⚙️ ローカルコマンド

APIキー未設定でも /fly /layers /layer /basemaps /search /camera で地図操作を試せます

🧪 コード実行サンドボックス

runCode ツールでAI生成JSを sandbox iframe（opaque origin）内で実行。集計・加工・座標計算が無料・高速。地図操作は api ブリッジ経由のみ

📜 履歴・透明性

履歴はプロジェクト単位で localStorage に永続化（最大200件・ヘッダーの🗑でクリア）。AIのツール実行は「実行: ...」とログ表示

🔐 セキュリティ

APIキーは localStorage のみ・送信先は Google のAPI（HTTPS）のみ。Google Cloud 側でAPI制限推奨。window.kasugaiApi は開いたブラウザ内からのみ実行可能で外部経路なし。影響の大きい操作（プロジェクト切替・設定適用・停止等）はユーザー明示時のみ

🤝 エージェント連携

ADK等のフレームワークは内蔵せず、外部で構築されたエージェント（Antigravity等）をAPIで呼び出す構成。アプリが担うのはチャットUI・地図操作・応答往復のみで、静的WEBサーバーのまま成立します。Google → エージェント タブでエンドポイントURL・Bearerトークン（任意）を設定し「チャットを外部エージェントへ送信」をONにすると、チャット入力が Gemini より優先してそのエンドポイントへ POST されます。要求JSONは {message, project, camera, layers, history}、応答JSONは {reply, actions:[{name,args}]} で、actions はAIチャットと同名のツール（flyTo・setLayerVisible 等）として順次実行されます。エンドポイント側ではこのオリジンからの CORS 許可が必要です

🧩 AIプラグイン生成（自己拡張）

チャットに「〜するプラグインを作って」と頼むと、AIがコードを生成してブラウザ内 IndexedDB に保存・即時有効化。適用前にコード全文の確認ダイアログが出ます。読み込みエラーはAIへ返るため、修正→再保存の自律ループが回ります。Google → エージェント タブで一覧・有効化・コード確認・.kasp 出力/取込・削除が可能。ストレージ保存のため配布物とは分離され、気に入ったものだけ PLUGIN/ に登録して公開できます

📊 データ取得・加工・表示パイプライン

fetchData（外部URL取得・CORS前提）と getLayerGeoJson（読込済みレイヤーのGeoJSON取り出し・描画切り捨て時も全件）でデータを取得し、runCode で任意の加工・集計・変換を行い、addDataLayer で GeoJSON を直接レイヤー表示。feature の properties に simplestyle 属性（marker-color/fill/stroke/description 等）を書けば色分け・ポップアップも制御できます。一時レイヤーは .kasc には含まれません。URL・ファイル指定のレイヤーを .kasc に永続追加する場合は addLayer（geojson/layer/geoparquet/flatgeobuf/gpkg/duckdb/sql の各行タイプに対応、duckdb は where=/limit=/bbox=auto 等のオプション指定可）を使います

🌐 実行環境ティア（公開/ローカルの使い分け）

AI機能は操作の影響範囲で3ティアに分かれます。static（静的配信のみ）と workers（Cloudflare Pages/Workers 公開環境）では、セッション内に閉じる安全な機能（地図操作・runCode・データ加工・IndexedDBプラグイン生成）を誰でも利用可能。local（ローカルサーバー版）では永続化・共有・システムに触れる高権限機能（/api/fetch によるCORS回避の取得プロキシ、/api/plugins による PLUGIN/ へのプラグイン公開、ファイル保存）が使えます。フロントは /api/capabilities で能力を検出してツール・UIを出し分け、バックエンド無しでも安全機能のみで動作します。昇格ルートは「IndexedDB草稿 → .kasp出力 → ローカル版で公開ボタン → PLUGIN/」です

ローカルサーバー版の独自API（公開環境では無効）

GET  /api/capabilities   → {"tier":"local","features":["fetchProxy","pluginWrite","fileWrite",...]}
GET  /api/fetch?url=...  → CORS回避のGETプロキシ（http/httpsのみ・30秒・20MB上限）
POST /api/plugins        → {"id","name","version","description","layer","code"}
                           PLUGIN/<id>/plugin.js・manifest.json を作成し plugins.json に登録
DELETE /api/plugins/{id} → プラグインの公開取り消し（PLUGIN/<id>/ と plugins.json 登録を削除）
GET  /api/files?project= → projects/<project>/DATA/ 内のファイル一覧（{name,size,modified}[]）
PUT  /api/files/{project}/{path} → DATA/ へボディを書き込み（サブフォルダ可・64MB上限）
DELETE /api/files/{project}/{path} → DATA/ 内のファイルを削除

プラグインIDは半角英数・-・_ のみ（64文字まで）。公開・削除は実ファイルを書き換えるため、フロント側では必ず確認ダイアログが出ます。公開環境（Pages/Workers）に同等の無認証書き込みAPIを置かないでください。
