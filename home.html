KASUGAI Canvas v3.4.9

ローカルPC・ブラウザ完結で動作する 2D/3D データ可視化システムの技術選定

📋 概要

KASUGAI Canvas は、CesiumJS + Three.js を核とした 2D/3D データ可視化システムです。Re:Earth GeoSuite との互換性を意識した GIS 基本機能に加え、KASUGAI 独自の FLY 機能を追加しています。

v3.4.2 以降、地図タイル・検索・レイヤー取得は CesiumJS が直接行い、Rust サーバーはバージョン管理・シャットダウン・ヘルスチェック API のみ提供します。

▶ デモサイトを開く（インストール不要・ブラウザで即起動）

デモは GitHub Pages 上の静的配信版です。設定の保存・サーバー経由の一部機能は無効ですが、地図閲覧・Fly など主要機能はそのまま試せます。

🗺️ GIS 基本機能（Re:Earth GeoSuite コンパチブル）

Re:Earth GeoSuite と同様の GIS・デジタルツイン機能を実装しています。

📝 インスペクター一括設定

xyz: / 3dtiles: / geojson: / base: / info: / cam: / legend: 等を行単位で一括設定

🗺️ ベースマップ

base: または xyz: 行で指定。Basemap セレクタから 1 つだけアクティブ化

🔧 システムレイヤ制御

layer: 行で既存レイヤー名を指定し、表示 / 非表示を初期制御

➕ レイヤー追加・管理

XYZ タイル、3D Tiles、GeoJSON を URL 指定で追加。Layers パネルで表示切替

📑 レイヤー一覧UI

読み込んだレイヤーの表示切替、並び順変更、設定の永続化を視覚的に操作

📂 レイヤグループ化

/ 通常グループ、// 排他グループ。ラジオボタンのような排他制御

🖼️ 凡例表示

legend: 行で画像 URL を指定。Legend タブに凡例画像を一覧表示

🔎 住所検索

国土地理院 / Yahoo ジオコーダ API を使い、住所・施設名で検索＋ FlyTo

🧬 ベクトル検索

GeoJSON / CSV レイヤーの属性値をレイヤー・属性・文字列で絞り込み FlyTo

📊 属性・値一覧

表示中のベクトルレイヤー属性を一覧。文字列検索・列ソート・行クリック FlyTo

🎥 カメラプリセット

cam: 行で登録した位置へワンクリック FlyTo。緯度・経度・高さ・ピッチ・方位を設定

ℹ️ Info 表示

info: 行で外部 HTML を Info タブに表示。プロジェクト説明やドキュメントを埋め込み

📤 Share（位置情報共有）

カメラ位置を URL ハッシュに保存。共有 URL コピーで同じ視点を共有

🗺️ GeoJSON 3D ドレープ制御

地面 / Terrain / 3D Tiles のどれに張り付くかをインスペクター行または設定で切替

⛰️ Terrain / Shadow

地形表示と影表示の ON/OFF をワンクリックで切り替え。地形ソースは Re:Earth(楕円体高 / 標高)と国土地理院 DEM(5m+10m / 1m、TP基準)から選択可能

🧭 ナビゲーション

方位コンパス、2D / 3D 切替、Orbit / Fly モード切替、北リセット

📊 属性（Attr）表示

Re:Earth上の地物を選択した際に、属性情報を一覧表示

🌐 ハイブリッド配布・公開構成

KASUGAI Canvas は、ブラウザ完結の CesiumJS フロントエンドに整理されています。Rust/Axum サーバーはあくまで 最小限の静的ファイル配信で、web/ ディレクトリそのものを nginx / Apache / IIS / GitHub Pages などに置くだけで一般公開もできます。

📦 ローカル・納品

kasugai_canvas.zip または NSIS インストーラーで配布。kasugai_canvas.exe と同じ場所に web/・projects/ を配置します。

🌐 WEB 公開

web/ を静的サーバーにアップロード。同一オリジン内の projects/<id>/DATA/ を相対パスで参照できます。

🔒 読み取り専用

プロジェクトファイルは Web サーバー側の権限で書き込み禁止にできます。変更は「エクスポート(.kasc)」でローカルに落として差し替えます。

⚠️ 公開時の注意

外部 3D Tiles / GeoJSON は CORS が必要。Yahoo AppID 等の認証情報を .kasc に書くと公開サイトで漏洩します。

🎬 プレゼンテーション機能（追加機能）

KASUGAI Canvas 独自に追加した、視点を動かして周囲に共有するプレゼンテーション機能です。

🛩️ Fly モード

GeoJSON ルート自動追従・手動操縦、速度・高さ・ピッチ調整、ルート描画

✏️ ルート描画

Orbit モードで右クリックによるルート作成。高さ編集・保存・Fly 実行まで一連

🎬 Google Earth 風 FlyTo

距離に応じた飛行時間＋ズームアウトから降下する弧を描いて移動

🤖 AIチャット（Gemini連携）

右下の Chat パネルから Gemini API（function calling）で地図を操作できます。設定 → Google タブで Gemini API キー・モデルを設定します。

💬 地図操作チャット

「◯◯へ飛んで」「レイヤを消して」等をAIが実行。flyTo・レイヤ切替・ベースマップ・検索・地形/効果・地下表示・断面クリップ・Flyパス・プロジェクト切替まで網羅。AI移動はドローン視点（対象地上+200m・-30°）が既定

⚙️ ローカルコマンド

APIキー未設定でも /fly /layers /layer /basemaps /search /camera で地図操作を試せます

🧪 コード実行サンドボックス

runCode ツールでAI生成JSを sandbox iframe（opaque origin）内で実行。集計・加工・座標計算が無料・高速。地図操作は api ブリッジ経由のみ

📜 履歴・透明性

履歴はプロジェクト単位で localStorage に永続化（最大200件・ヘッダーの🗑でクリア）。AIのツール実行は「実行: ...」とログ表示

🔐 セキュリティ

APIキーは localStorage のみ・送信先は Google のAPI（HTTPS）のみ。Google Cloud 側でAPI制限推奨。window.kasugaiApi は開いたブラウザ内からのみ実行可能で外部経路なし。影響の大きい操作（プロジェクト切替・設定適用・停止等）はユーザー明示時のみ

🤝 エージェント連携方針

ADK等のフレームワークは内蔵せず、外部で構築されたエージェント（Antigravity等）をAPIで呼び出す構成。アプリが担うのはチャットUI・地図操作・応答往復のみで、静的WEBサーバーのまま成立します

📝 インスペクター設定（完全版）

設定 → Inspector タブで .kasc 形式を編集・適用します。このページが設定仕様の正本です。

Step 2: 設定方法

設定 → Inspector（歯車タブ）のテキスト欄に、以下の形式で行ごとに入力し「登録」を押してください。設定行は順不同です。

xyz: OpenStreetMap | https://tile.openstreetmap.org/{z}/{x}/{y}.png
base: 地理院タイル 全国最新写真 | https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg | 出典：国土地理院 | maxZoom=18
base: 地理院タイル 標準地図 | https://cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png | 出典：国土地理院 | maxZoom=18
3dtiles: 東京都/千代田区（建築物LOD1） | https://example.com/tileset.json | off
geojson: 東京都/行政区域 | https://example.com/行政区域.geojson | on
background: #ffffff
info: https://example.com/project-info.html
cam: 東京駅|35.653108|139.761449|h=2200.6|p=-30
legend: 凡例|https://example.com/legend.png

基本書式

種類:タイトル|URL|出典|オプション名=値|on/off

URLが DATA/... 等の相対パスなら projects/<project>/DATA/ 配下に解決。任意位置の on/off（false 可・大文字小文字不問）で初期表示を指定。

設定種類

base: ベースマップ(先頭が既定) | maxZoom= / tileSize= / opacity= / proxy=off
xyz: タイルレイヤ | 同上+off
3dtiles: / geojson:(layer:) レイヤ | off / proxy=off
cam: カメラプリセット | cam:名|緯度|経度|h=高さ|p=ピッチ|d=方位
fly_geojson: Flyパス | s=速度 h=高さ p=ピッチ step= loop=true
info: InfoパネルHTML / legend: 凡例画像 / background: 背景色 / yahooAppId: Yahoo検索ID

グループ化ルール

/・\＝通常グループ（一括ON/OFF）、//・\\＝排他グループ（同時に1つだけ表示・ラジオ動作）。全グループの初期表示は折りたたみです。

未対応の記法（注意）

Re:Earth GeoSuite 由来の以下の記法は本アプリでは未実装です：layer: によるシステムレイヤ制御、max=/zoom=（maxZoom= を使用）、行単位ドレープ（| terrain 等→設定タブのグローバル設定を使用）、attrUrlOpen:、\ による初期展開。

ローカルファイルの追加（デモ用データ・Chromium系）

  1. Inspectorタブ「フォルダを選択」で DATA/ を指定（File System Access API・変更可・IndexedDB保持）
  2. ファイル選択 → 「DATA/ に保存して追加」 で書き込み＋設定追記＋登録まで一括
  3. 「設定行のみ追加」は追記のみ（手動コピー用）、「今すぐプレビュー」は一時表示
  4. 保存したDATA/ファイルは .kasc と共に配布すればデモサイト化できます

📖 使い方

基本の流れ

  • 設定は projects/<project>/kasugai_canvas.kasc に記述します。
  • ローカルデータは projects/<project>/DATA/ 以下に置き、設定から相対パスで参照できます。
  • 「エクスポート(.kasc)」ボタンで変更をダウンロードし、設定ファイルと差し替えて保存してください。
  • web/ ディレクトリは通常の HTTP サーバーにそのまま配置できます。

起動方法（通常のHTTPサーバー）

cd web
python -m http.server 8520

web/ をドキュメントルートに置くだけです。ブラウザで http://127.0.0.1:8520/ を開いてください。

起動方法（Rustサーバー / 開発）

cargo run --manifest-path server\Cargo.toml
# または
python run.py            # 開発起動
python run.py --release  # リリース版を起動

ブラウザで http://127.0.0.1:8510/ を開いてください。ポートは KASUGAI_CANVAS_PORT 環境変数で変更できます。インスペクター設定は projects/<project>/kasugai_canvas.kasc に保存されます。

プロジェクト構成

web/                    # フロントエンド資産(静的配信のみで動作)
├─ index.html / app.js / styles.css
└─ projects/
   ├─ projects.json      # プロジェクト一覧 [{"id":"...","title":"..."}]
   └─ <project_id>/
      ├─ project.json     # 表示名等
      ├─ kasugai_canvas.kasc  # インスペクター設定
      └─ DATA/            # ローカルGeoJSON・3D Tiles・画像等

設定内の相対パス（例: DATA/sample.geojson）は projects/<project_id>/DATA/ に解決されます。Rustサーバー使用時は同構成の projects/ をサーバーと同階層に配置します。

設定の保存

静的サーバーでは設定をサーバーに保存しません。インスペクターの「エクスポート(.kasc)」でダウンロードし、対象プロジェクトの kasugai_canvas.kasc と差し替えてください。

リリースビルド

python run.py -B

配布用 ZIP（kasugai_canvas.exe + web/ + projects/）と、NSIS が利用可能な場合はインストーラーを download\ に作成します。既定のインストール先は C:\kasugai\kasugai_canvas です。

自動更新

Rust サーバー起動時は、設定パネルから最新リリースの確認・自動更新が行えます。更新時は EXE を自動的に差し替えて再起動します。

インスペクター設定

xyz: OpenStreetMap | https://tile.openstreetmap.org/{z}/{x}/{y}.png
base: 地理院タイル 全国最新写真 | https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg | 出典：国土地理院 | max=18
cam: 東京駅 | 35.653108 | 139.761449 | h=2200.6 | p=-30
info: https://example.com/project-info.html

1 行 種類: 値 形式でレイヤー、ベースマップ、カメラ、Info、凡例等を記述します。完全な書式・オプション・ローカルファイル追加手順は本ページ上部の「インスペクター設定（完全版）」を参照してください。

FLY 機能（KASUGAI 独自追加機能）

  1. kasugai_canvas.kasc に fly_geojson: ルート名 | URL | speed=10 | height=100 | pitch=-30 を追加
  2. ナビゲーションツールバーから Fly モードに切り替え、ドロップダウンでルートを選択
  3. マウスホイール / キー + / - で速度、キー Q / E で高さ補正を調整
  4. Orbit モードで Draw タブから右クリックで点を追加、右ダブルクリックでルート描画終了
